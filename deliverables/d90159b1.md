## ⚙️ מפרט טכני לכל Short

הכותרת נושאת את משקל ה-SEO הגבוה ביותר. Best practice 2026: מיקום מילת המפתח ב-3 המילים הראשונות, כותרת עד 60 תווים, description של 150–200 מילה עם keywords ו-LSI keywords.

Hashtags — שמים בתיאור, לא בכותרת. שלושת ה-hashtags הראשונים מופיעים אוטומטית מעל הכותרת כ-clickable links.

Captions burned-in: צופים צופים ללא צליל → completion rate גבוה יותר. YouTube גם מאנדקס טקסט captions לחיפוש.

| פרמטר | ספציפיקציה |
|--------|-------------|
| **פורמט** | 9:16 vertical, 1080×1920px |
| **אורך** | 50–60 שניות (מקסימום views) |
| **Caption** | Burned-in, עברית, 32–42 תווים לשורה, 2 שורות מקסימום |
| **Hook** | שניות 0–3: שאלה / טענה מפתיעה / מספר |
| **Hashtags** | 3–5 בתיאור (לא בכותרת) |
| **CTA** | "הפרטים בביו 👇" + link בביו לדף נחיתה/contact |
| **Related Video** | לקשר כל Short לסרטון ארוך רלוונטי בערוץ |
| **פרסום** | שלישי + חמישי, 18:00–20:00 (peak engagement) |
