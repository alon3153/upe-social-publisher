## חלק ו׳ — הגדרת Salesforce: LeadSource='Referral-Digital'

### לוגיקת תיעוד

עקב referrals כ-Lead Source נפרד ב-CRM מהמגע הראשון. תעד שם המפנה, תאריך ה-referral, וסוג הקשר — זה מאפשר למדוד אילו לקוחות מפנים הכי הרבה ואיך referral leads מבצעים לעומת מקורות אחרים.

### Salesforce Lead Field Mapping

| שדה ב-SF | ערך / לוגיקה |
|---|---|
| `LeadSource` | `Referral-Digital` |
| `LeadSource_Detail__c` *(Custom Field)* | `Google-Review` / `LinkedIn-Recommendation` / `LinkedIn-DM` / `WhatsApp-Referral` |
| `Referring_Account__c` *(Lookup)* | Account של הלקוח המפנה |
| `Referring_Contact__c` *(Lookup)* | Contact של האיש שהמליץ |
| `Referral_Date__c` | תאריך שהתקבל ה-lead |
| `Referral_Event_Project__c` | שם הפרויקט שממנו צמח ה-referral |
| `Campaign` | קישור ל-Campaign: `UPE_Referral_Digital_2026` |

> 💡 שיטת best practice: שמור את `LeadSource` ל-5-7 ערכים מנורמלים, והוסף custom field `LeadSource_Detail__c` עם הפרטים הספציפיים (e.g., "Google-Review" או "LinkedIn-Recommendation"). כך הדוחות ניתנים לסקייל ולניהול.

### Salesforce Automation Rules (Process Builder / Flow)

```
TRIGGER: New Lead Created WHERE LeadSource = 'Referral-Digital'
→ ACTION 1: Create Task for BDR "Qualify referral lead within 48h"
→ ACTION 2: Send internal Slack alert to Sales Team
→ ACTION 3: Auto-add to Campaign: 'UPE_Referral_Digital_2026'
→ ACTION 4: Set Lead.SLA_Due_Date = TODAY + 2 days
```
