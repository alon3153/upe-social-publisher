## PART 4 — JSON-LD SCHEMA (Event + Organization + FAQ)

JSON-LD is the only format Google recommends — embed structured data as a JSON-LD script tag in the document head or body. Event schema is one of the few types where Google still ships a full rich result for non-government, non-health sites. FAQ and HowTo lost theirs in 2023. Event did not. If your business runs anything date-bound, this is one of the highest-ROI types to ship.

Paste the following **three JSON-LD blocks** in the `<head>` of the page (or immediately before `</body>`). They can be combined into one `<script>` tag using `@graph`.
