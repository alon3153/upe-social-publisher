## 🎯 מה הבעיה שאנחנו פותרים

ל-Salesforce יש שדה `LeadSource` בודד על ה-Lead object — וזה כל סיפור ה-attribution out-of-the-box. ה-"Web" שם מקופל לתוכו organic, paid search, paid social, email ו-direct — בבת אחת. כלומר, כרגע כל ליד שמגיע מ-LinkedIn Organic, Google Organic, Instagram Ad, Referral, או Word of Mouth — נרשם "Other" או "Web" ו-**attribution נעלם לחלוטין**.

השאלה שנשארת ללא מענה: אילו קמפיינים, פרסומות, או נקודות מגע יצרו בפועל את ה-pipeline? Salesforce אומר "Paid Social" — ושם מסתיים הנתיב.

**מה נרוויח מהתיקון:** לדעת מאיפה מגיעות הזדמנויות חדשות יעזור לנו למקם את אנשי המכירות ואת החברה בהשקעת הזמן והכסף הנכונים.

## 🗂️ חלק א׳ — עדכון ה-Picklist: `LeadSource` על ה-Opportunity Object

### הוראות: Setup → Object Manager → Opportunity → Fields & Relationships → LeadSource

**ערכי ה-Picklist החדשים (UPE-Specific) — מחליפים את ה-default:**

| # | ערך (API Name) | תיאור לנציג | מתי לבחור |
|---|---|---|---|
| 1 | `LinkedIn – Organic` | פוסט אורגני / DM ישיר ב-LinkedIn ללא תשלום | ליד שפנה אחרי שראה תוכן אורגני בלינקדאין |
| 2 | `LinkedIn – Paid` | מודעת LinkedIn (Sponsored Content / InMail) | ליד שהגיע ממודעת ממומנת בלינקדאין |
| 3 | `Google – Organic` | חיפוש אורגני (SEO) | ליד שמצא אותנו דרך חיפוש גוגל ללא פרסומת |
| 4 | `Google – Paid (Search)` | מודעת Google Search / PPC | ליד שהגיע ממודעה בגוגל |
| 5 | `Instagram – Organic` | פוסט / Story / Reel אורגני | ליד שפנה אחרי תוכן אינסטגרם |
| 6 | `Instagram – Paid` | מודעת Instagram ממומנת | ליד שהגיע ממודעת Meta/Instagram |
| 7 | `Referral – Client` | לקוח קיים שהפנה | לקוח ששלח מישהו אלינו בפועל |
| 8 | `Referral – Partner` | שותף / ספק / אינטגרטור | גורם חיצוני שאינו לקוח ישיר |
| 9 | `Word of Mouth` | שמועה / המלצה בלתי פורמלית | "שמעתי עליכם מ..." — אך לא Referral מוגדר |
| 10 | `Event / Conference` | פגישה בכנס, תערוכה, אירוע | ליד שנוצר פנים-אל-פנים באירוע |
| 11 | `Direct Outreach – Sales` | יציאת מכירות ישירה (cold/warm) | נציג יצר קשר יזום |
| 12 | `Email Marketing` | ניוזלטר / רצף אוטומטי | ליד שהגיב לקמפיין email |
| 13 | `Website – Form` | טופס יצירת קשר / דף נחיתה | מילא טופס באתר (ללא קשר למקור) |
| 14 | `Other – Specify in Notes` | אחר — מחייב הסבר | ⚠️ חייב להיות עם הסבר בשדה `Description` |

> **כלל ה-"Other":** מומלץ להשתמש ב-`LeadSource` עם סט מוגבל של ערכים (יותר מדי ערכים הופך את השדה לבלתי-ניתן לניהול), ובמקביל לשמור שדה `Campaign` lookup לפירוט. לכן: `Other` אצלנו **מחייב הסבר** — כך שנוכל בסוף כל רבעון לבדוק אם יש ערך שחסר.

## 🔧 חלק ב׳ — Validation Rule: חובת מילוי LeadSource בכל Opportunity חדשה

### מטרה
יש להגדיר את השדה בעת יצירה ולא ידנית בדיעבד; רוב ה-drift מגיע ממילוי ידני ומרשימה ארוכה מדי — לא מ-Salesforce עצמו.

### הוראות: Setup → Object Manager → Opportunity → Validation Rules → New

**Rule Name:** `LeadSource_Required_On_New_Opportunity`

**Active:** ✅ כן

**Description:**
```
UPE Attribution Rule: LeadSource חייב להיות מלא בכל הזדמנות חדשה.
אם אינך בטוח — בחר "Other – Specify in Notes" ורשום הסבר בשדה Description.
נוצר: 09/2026 | בעלים: Marketing/RevOps
```

**Error Condition Formula:**
```javascript
AND(
  ISNEW(),
  ISBLANK(LeadSource)
)
```

**Error Message:**
```
⚠️ שדה "מקור הליד" (Lead Source) הוא חובה.
בחר את הערך המתאים מהרשימה. לא בטוח? בחר "Other – Specify in Notes" ורשום הסבר בתיאור.
ללא מידע זה לא נוכל למדוד attribution ולהשקיע תקציב נכון.
```

**Error Location:** `Field → LeadSource`

## ⚡ חלק ג׳ — Salesforce Flow: העברת LeadSource מ-Lead ל-Opportunity בעת המרה

> **הבעיה:** שדה `Lead.LeadSource` הוא standard field ומועתק אוטומטית ל-`Contact.LeadSource` ול-Opportunity — אך שדות custom (כולל UTM) אינם עוברים אוטומטית. יש לקנפג map ב-Lead Conversion Setup, ולכתוב לוגיקה נפרדת אם רוצים UTM data על ה-Opportunity.

### שלב 1 — וודא Mapping של LeadSource ב-Lead Conversion:

```
Setup → Lead Settings → Map Lead Fields
Lead Field: LeadSource → Opportunity Field: LeadSource ✅ (אמור להיות מוגדר כברירת מחדל)
```

**בדוק:** פתח הגדרת Map Lead Fields וודא שהמיפוי קיים. אם לא — הוסף.

### שלב 2 — Flow: Auto-Populate LeadSource מ-Converted Lead (כגיבוי)

**Flow Type:** Record-Triggered Flow
**Object:** Opportunity
**Trigger:** A record is created
**Condition:** `LeadSource IS NULL` AND `LeadSource__c (Campaign Source - custom field) IS NOT NULL`

```
Flow Name: UPE_Opportunity_LeadSource_AutoPopulate
Trigger: When Opportunity is Created
Condition: ISBLANK({!$Record.LeadSource})
Action: Update Record → LeadSource = {!$Record.UPE_Channel_Detail__c}
```

*(רלוונטי רק אם מוסיפים שדה custom `UPE_Channel_Detail__c` — ראה חלק ד׳)*

## 📊 חלק ד׳ — שדה Custom נוסף (אופציונלי אך מומלץ): `UPE_Channel_Detail__c`

ה-picklist הסטנדרטי של LeadSource הוא גס מדי לדיווח שיווקי. מומלץ לצמד אליו שדות UTM custom ו-Channel field מ-automation.

### הוראות יצירה: Object Manager → Opportunity → Fields → New

| פרמטר | ערך |
|---|---|
| Field Type | `Text` |
| Field Label | `Channel Detail (UPE)` |
| API Name | `UPE_Channel_Detail__c` |
| Length | 255 |
| Help Text | "פירוט נוסף לגבי מקור הליד: שם קמפיין, שם הממליץ, שם הכנס וכו׳. לדוגמה: 'LinkedIn Campaign – Israel CMOs Q3 2026'" |
| Visible to all profiles | ✅ |
| Required | ❌ (לא חובה — הוא שדה הרחבה בלבד) |

**מטרה:** לאפשר לנציגים לכתוב `"LinkedIn Organic – פוסט וידאו אירוע סוף שנה"` ולא רק לבחור `LinkedIn – Organic`. זה **gold data** לניתוח רבעוני.

## 📌 הקשר אסטרטגי — למה זה P2 ולא P3

ה-CFO רוצה לדעת אילו השקעות שיווקיות מניבות הכנסות — ואנחנו תקועים עם נתונים חלקיים ממקורות שלא מסתדרים. זהו ה-attribution gap שמשווקים מתמודדים איתו כל יום. עבור UPE, שבה תקציב דיגיטל מתחרה עם Referral ו-Word of Mouth כמקורות מסורתיים חזקים, נציגים צריכים לרוץ על דוחות Lead Source תקופתיים כדי לקבוע היכן הם ייצרו את הפעילות הרווחית ביותר — ובעת קביעת תקציב שיווקי, דוח זה הוא הכלי המרכזי.

**ל-UPE ספציפית:** אם נגלה ש-70% מה-Opportunities הסגורות מגיעות מ-`Referral – Client` ורק 5% מ-`LinkedIn – Paid` — זו הצדקה ישירה לכיוון תקציב מחדש.
