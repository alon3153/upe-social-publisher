## PART 3 — הגדרת Salesforce (Technical Spec לצוות ה-CRM)

Salesforce משתמש ב-Campaigns ו-Campaign Members לattribution: Campaign Member מקשר Lead לקמפיין ומתעד סטטוס, ו-Primary Campaign Source משמש לfirst-touch attribution.

### Web-to-Lead Hidden Fields (להוסיף לטופס):

```html
<!-- שדות נסתרים — ממולאים אוטומטית מ-UTM / JavaScript -->
<input type="hidden" name="lead_source"   id="lead_source"   value="" />
<input type="hidden" name="utm_source"    id="utm_source"    value="" />
<input type="hidden" name="utm_medium"    id="utm_medium"    value="" />
<input type="hidden" name="utm_campaign"  id="utm_campaign"  value="" />
<input type="hidden" name="event_type"    id="event_type"    value="" />
```

### JavaScript לקריאת UTM ואכלוס אוטומטי:

```javascript
// יש להוסיף לdark של הדף — לפני </body>
(function() {
  const params = new URLSearchParams(window.location.search);
  const utmSource   = params.get('utm_source')   || '';
  const utmMedium   = params.get('utm_medium')   || '';
  const utmCampaign = params.get('utm_campaign') || '';

  // Map utm_source → Salesforce LeadSource picklist value
  const leadSourceMap = {
    'instagram': 'Social/Instagram',
    'linkedin':  'Social/LinkedIn'
  };
  const leadSource = leadSourceMap[utmSource.toLowerCase()] || 'Social';

  // Populate hidden fields
  document.getElementById('lead_source').value   = leadSource;
  document.getElementById('utm_source').value    = utmSource;
  document.getElementById('utm_medium').value    = utmMedium;
  document.getElementById('utm_campaign').value  = utmCampaign;
})();
```

### Salesforce Web-to-Lead Endpoint (לשלב בטופס):

```html

  <input type="text"  name="first_name"   placeholder="שם פרטי *"   required />
  <input type="text"  name="last_name"    placeholder="שם משפחה *"  required />
  <input type="text"  name="company"      placeholder="חברה *"       required />

  <!-- Event Type — ממולא מכפתורי הבחירה -->
  <input type="hidden" name="00N_EVENT_TYPE__c" id="event_type" value="" />
```

> **📌 הערה לCRM Admin:** יש ליצור Custom Field `Event_Type__c` (Text) ב-Lead Object לפני הטמעת הטופס. שדה `LeadSource` צריך לכלול ערכי Picklist: `Social/Instagram`, `Social/LinkedIn`.
