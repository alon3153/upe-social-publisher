## חלק ד׳: 51 כותרות ממוטבות + 2 שורות תיאור + CTA

> **כללי metadata 2026:**
> Keep under 60 characters. Anything longer gets truncated. Lead with the keyword — the first 30 characters carry the most ranking weight.
> The first 100-150 characters appear before "Show More" — this golden zone functions as a search snippet that directly influences CTR.
> A well-optimised description should include a compelling hook in the first two lines, your primary keyword within the first 150 characters, a detailed summary, timestamps, links, a CTA, and 2-3 hashtags.

**פורמט כל entry:**
```
[מספר] VIDEO TITLE (≤60 chars)
📌 DESCRIPTION LINE 1 (keyword + outcome, ≤80 chars)
📌 DESCRIPTION LINE 2 (CTA + link placeholder)
🏷️ TAGS (5 ראשיים)
📂 PLAYLIST
```
