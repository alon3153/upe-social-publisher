## חלק ג׳ — End Screen Configuration

> End screens מופיעים ב-5–20 השניות האחרונות של הוידאו ומאפשרים עד 4 אלמנטים קליקביליים: וידאו, פלייליסט, כפתור מנוי, ערוץ, וקישור חיצוני.
>
> Benchmark לעסקים: End screen click rate בריא הוא 5–8%. מתחת ל-3% מצביע שהאלמנטים לא מספיק בולטים או שה-CTA הורבלי לא מספיק משכנע.

---

### ⚙️ הגדרות End Screen — מה לשים (YouTube Studio)

עבור ערוצי עסקים, ה-configuration הכי יעיל הוא שני אלמנטים: כרטיס וידאו אחד לוידאו הכי רלוונטי + כפתור מנוי. הוספת יותר אלמנטים מפצלת תשומת לב ומפחיתה clicks על הכרטיס הראשי.

```
┌─────────────────────────────────────────┐
│           END SCREEN LAYOUT              │
│                                         │
│  [ELEMENT 1]          [ELEMENT 2]        │
│  📹 Video Card        🔔 Subscribe       │
│  "הוידאו הבא         Button              │
│   בפלייליסט"                            │
│                                         │
│  + External Link (אם יש מנוי YouTube   │
│    Premium) → Landing Page UPE          │
└─────────────────────────────────────────┘
```

**הוראות טכניות ב-YouTube Studio:**
1. היכנס ל-YouTube Studio → בחר וידאו → **Editor**
2. לחץ **End Screen** → **Add Element**
3. **Element 1:** Video → "Best for viewer" (ה-algorithm בוחר) **או** "Specific video" (הוידאו הבא בפלייליסט)
4. **Element 2:** Subscribe button
5. **Element 3 (אופציונלי — דורש YouTube Partner Program):** External Link → `upe.co.il/contact`
6. מקם אלמנטים בפינה ימין-תחתון (RTL: פינה שמאל-תחתון ברוב עיצובי הוידאו)
7. וודא שהמסגרות האחרונות **נקיות ויזואלית** מתוכן — תכנן את ה-End Screen לפני הצילום: השאר שטח ויזואלי נקי ב-15–20 השניות האחרונות כדי שהאלמנטים לא יכסו תוכן חשוב.
