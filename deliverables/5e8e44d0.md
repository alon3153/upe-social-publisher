## עקרון יסוד: מדוע "מצאתי בגוגל" אינו מספיק

תעבורת גוגל ממומנת ואורגנית "מדממת" זו לזו ברמת הסיגנל. UTMs חסרים, Referrers חסויים, GCLIDs שנמחקו, ופערים בין-מכשיריים — כולם משבשים את ההבחנה. כאשר ליד אומר "מצאתי אתכם בגוגל", זה יכול להיות: חיפוש אורגני, מודעת Google Ads, YouTube, Google Display — וכל אחד מהם מייצג השקעה שיווקית שונה לחלוטין עבור UPE.

| `utm_medium=organic` + `utm_source=google` | חיפוש אורגני מ-Google | **Organic Search – Google** |
| `gclid=XXXX` בURL (ללא UTM מפורש) | Google Ads עם Auto-Tagging פעיל | **Paid Search – Google** |

| `utm_medium=video` + `utm_source=youtube` | YouTube Ads | **Paid Video – YouTube** |

## חלק ב׳ — תשתית טכנית: לכידת UTM בטפסי הפנייה

### מה חייב להיות בכל טופס יצירת קשר של UPE

יש להוסיף שבעה שדות סמויים: `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `referrer`, ו-`landing_page` — ולשתול סקריפט שקורא את ה-URL ואת `document.referrer` בעת הטעינה וממלא אותם.

#### קוד JavaScript — להדביק ב-`<head>` של כל Landing Page של UPE

```javascript
// UPE Lead Attribution Script v1.0
// מטרה: לכידת UTM ו-Referrer בכל טופס פנייה
// ⚠️ DRAFT — לאישור Alon לפני הטמעה

(function () {
  // קריאת UTM מה-URL הנוכחי
  function getParam(name) {
    return new URLSearchParams(window.location.search).get(name) || '';
  }

  // שמירה ב-sessionStorage (first-touch בביקור זה)
  var params = ['utm_source', 'utm_medium', 'utm_campaign', 'utm_term', 'utm_content'];
  
  params.forEach(function (p) {
    // first-touch: כתוב רק אם אין ערך קודם (localStorage)
    if (!localStorage.getItem('upe_first_' + p)) {
      var val = getParam(p);
      if (val) localStorage.setItem('upe_first_' + p, val);
    }
    // last-touch: תמיד מעדכן
    var val = getParam(p);
    if (val) sessionStorage.setItem('upe_last_' + p, val);
  });

  // שמירת referrer ו-landing page
  if (!localStorage.getItem('upe_first_referrer')) {
    localStorage.setItem('upe_first_referrer', document.referrer || 'direct');
  }
  if (!localStorage.getItem('upe_first_landing')) {
    localStorage.setItem('upe_first_landing', window.location.pathname);
  }

  // מילוי שדות סמויים בכל הטפסים בדף
  function fillHiddenFields() {
    var fieldMap = {
      'upe_utm_source':    localStorage.getItem('upe_first_utm_source')   || '',
      'upe_utm_medium':    localStorage.getItem('upe_first_utm_medium')   || '',
      'upe_utm_campaign':  localStorage.getItem('upe_first_utm_campaign') || '',
      'upe_utm_term':      localStorage.getItem('upe_first_utm_term')     || '',
      'upe_utm_content':   localStorage.getItem('upe_first_utm_content')  || '',
      'upe_referrer':      localStorage.getItem('upe_first_referrer')     || '',
      'upe_landing_page':  localStorage.getItem('upe_first_landing')      || '',
      'upe_last_medium':   sessionStorage.getItem('upe_last_utm_medium')  || '',
      'upe_last_campaign': sessionStorage.getItem('upe_last_utm_campaign')|| ''
    };

    Object.keys(fieldMap).forEach(function (fieldName) {
      var el = document.querySelector('input[name="' + fieldName + '"]');
      if (el) el.value = fieldMap[fieldName];
    });
  }

  // הרץ בעת טעינה ובעת submit
  document.addEventListener('DOMContentLoaded', fillHiddenFields);
  document.addEventListener('submit', fillHiddenFields);
})();
```

> **⚠️ הערה טכנית:** כשל נפוץ: הגולש מגיע עם UTM לדף הנחיתה, קורא, עובר לדף צור-קשר — ושם ה-URL כבר נקי מפרמטרים. הסקריפט פותר זאת על-ידי אחסון ב-`localStorage`.

## חלק ד׳ — נוהל לנציג: שאלות Drill-Down לסיווג ידני

כאשר אין נתון טכני ברור, הנציג ישתמש בשאלות הבאות בשיחת הפתיחה (לא בסקר — בשיחה טבעית):

### שלב 1 — שאלת כיוון (Open-End)
> **"אם תוכל לשחזר את הרגע שנחשפת אלינו — מה היה הגורם הראשון?"**

### שלב 2 — Drill-Down לפי תשובה

| אם אמר/ה... | שאל/י בהמשך... | סיווג |
|---|---|---|
| "חיפשתי בגוגל" | "זכור לך אם זה היה תוצאה רגילה או מודעה עם 'ממומן'?" | Organic / Paid בהתאם |
| "ראיתי פרסום בגוגל" | "האם זה היה תיבה עם 'מודעה' / 'Sponsored'?" | **Paid Search – Google** |
| "מצאתי באתר מדריכים / Dun's" | "באיזה אתר בדיוק?" | **Referral** |
| "קיבלתי לינק ממישהו" | "מהרשת / מחבר / מלינקדאין?" | Word of Mouth / Social |
| "ראיתי פוסט / מאמר" | "בפלטפורמה כלשהי?" | Organic Social / Referral |
| "לא זוכר בכלל" | אל תסווג — בחר **Unknown** | Unknown |

> **כלל ברזל:** תשובת "מצאתי בגוגל" ללא פירוט נוסף → **אסור לסווג כ-Organic**. יש לבחור `Unknown – Requires Clarification` עד שיתקבל נתון מספיק.

## חלק ה׳ — כינוי UTM לקמפיינים ממומנים של UPE (Naming Convention)

UTM דורשים משמעת. הצוותים שמקבלים נתוני ייחוס נקיים משתמשים בכלי ממשל — לא בגיליונות או בניה ידנית.

### תבנית חובה לכל URL ממומן של UPE:

```
https://upe.co.il/[LANDING-PAGE]
  ?utm_source=[source]
  &utm_medium=[medium]
  &utm_campaign=[YYYY]_[market]_[campaign-name]
  &utm_content=[ad-variant]
  &utm_term=[keyword-or-audience]
```

### טבלת מיפוי ערכים (Controlled Vocabulary)

| פרמטר | ערכים מותרים בלבד |
|---|---|
| `utm_source` | `google`, `linkedin`, `meta`, `youtube`, `bing`, `email`, `partner`, `exhibition` |
| `utm_medium` | `cpc`, `display`, `video`, `paid_social`, `organic_social`, `email`, `referral`, `direct` |
| `utm_campaign` prefix | `2026_il_`, `2026_eu_`, `2026_global_` |
| `utm_campaign` suffix – סוג | `_incentive`, `_conference`, `_production`, `_brand` |
| `utm_content` | `[creative-type]_[variant]` לדוגמה: `video_v1`, `banner_cta_a` |

#### דוגמאות מלאות:

```
# Google Ads – קמפיין Incentive Travel לשוק ישראל
utm_source=google&utm_medium=cpc&utm_campaign=2026_il_incentive_travel&utm_content=search_v2&utm_term=חבילות_תמריץ_לעובדים

# LinkedIn Ads – כנסים לשוק אירופה
utm_source=linkedin&utm_medium=paid_social&utm_campaign=2026_eu_conference_production&utm_content=carousel_v1&utm_term=event_managers_eu

# Google Brand – חיפוש ממותג
utm_source=google&utm_medium=cpc&utm_campaign=2026_il_brand_upe&utm_content=brand_exact
```

## חלק ו׳ — לוגיקת סיווג אוטומטי ב-CRM (Workflow / Calculated Field)

יש להעביר UTM parameters דרך טפסי לכידת לידים ל-CRM כשדות מותאמים על רשומות Contact ו-Deal.

### כללי מיפוי אוטומטי (IF/THEN — לשימוש ב-HubSpot Workflow או Zapier):

```
IF upe_first_utm_source = "google" 
   AND upe_first_utm_medium = "cpc"
   AND upe_first_utm_campaign CONTAINS "brand"
   → upe_lead_channel_auto = "Paid Search – Google (Branded)"

IF upe_first_utm_source = "google" 
   AND upe_first_utm_medium = "cpc"
   AND upe_first_utm_campaign NOT CONTAINS "brand"
   → upe_lead_channel_auto = "Paid Search – Google (Non-Brand)"

IF upe_first_utm_medium = "organic" 
   OR (upe_first_referrer CONTAINS "google.com" 
       AND upe_first_utm_medium IS EMPTY 
       AND upe_gclid IS EMPTY)
   → upe_lead_channel_auto = "Organic Search – Google (Verified)"

IF upe_first_referrer CONTAINS "google.com"
   AND upe_first_utm_medium IS EMPTY
   AND upe_gclid IS EMPTY
   AND upe_first_utm_source IS EMPTY
   → upe_lead_channel_auto = "Organic Search – Google (Unverified)"

IF upe_first_utm_source = "linkedin" 
   AND upe_first_utm_medium = "paid_social"
   → upe_lead_channel_auto = "Paid Social – LinkedIn"

IF ALL EMPTY (utm_source, utm_medium, referrer)
   → upe_lead_channel_auto = "Direct / Unknown"
```

> **חשוב:** אם קמפיין Google Ads לא מתוייג ב-UTM, התנועה מגיעה ונראית אורגנית. ה-Referrer אומר "Google", אין פרמטר קמפיין, וכלי הייחוס מחשיב אותה כ-SEO. לכן: **כל מודעה ממומנת חייבת UTM — ללא יוצא מן הכלל.**
