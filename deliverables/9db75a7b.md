## חלק א׳ — מדריך תיקון חיבור Facebook API ב-Metricool (SOP מלא)

> **מטרה:** להביא את חשבון Facebook Page של UPE למצב מחובר ופעיל ב-Metricool, ולאמת שנתוני analytics מגיעים.

---

### שלב 1 — בדיקת מצב החיבור הנוכחי

1. היכנס ל-Metricool → **Connections Dashboard**
2. אתר את ה-Facebook Page של UPE
3. בדוק אם מופיע סטטוס "Connected" או הודעת שגיאה (❌)
4. תעד צילום מסך של המצב הנוכחי לפני כל שינוי

**שגיאות נפוצות לזהות:**
| קוד שגיאה | משמעות | פתרון |
|-----------|---------|--------|
| Token error | הפרופיל המחובר כ-Admin איבד הרשאות | ראה שלב 3 |
| Disconnected notification | שינוי Admin בעמוד Facebook או פקיעת הרשאות | ראה שלב 2 |
| Code 500 | שגיאה לא ידועה בצד Facebook, בדרך כלל downtime זמני | המתן ונסה שוב |

---

### שלב 2 — Refresh Connection (אם החשבון מחובר אבל נתונים חסרים)

עם Refresh Connection, סנכרון נתונים מתחיל אוטומטית.

1. Metricool → **Connections Dashboard**
2. לחץ על **"Refresh Connection"** ליד Facebook Page
3. היכנס עם פרופיל Facebook האישי שיש לו הרשאות **Admin** על העמוד
4. שים לב: לא ניתן להשתמש בחלק מפונקציות Metricool עד לריענון החיבור

---

### שלב 3 — Reconnect מלא (אם החיבור נותק לחלוטין)

היכנס ל-Facebook Business Tools Settings → מצא את Metricool ברשימת האפליקציות המחוברות → לחץ Remove כדי לבטל את כל ההרשאות.

לאחר מכן:
1. ודא שאתה מחובר לפרופיל Facebook הנכון — זה שיש לו Admin access לעמוד → בחר את Facebook Page של UPE → אשר את כל ה-permissions.
2. חזור ל-Metricool → Connections Dashboard → לחץ **"Connect Page"**
3. פתח טאב נוסף, התנתק מ-Facebook, חזור ל-Metricool, גש ל-Connection Dashboard, לחץ "Connect Page"
4. לאחר החיבור מחדש, הנתונים יסתנכרנו אוטומטית

> ⚠️ **חשוב:** כדי לשחזר נתונים היסטוריים, חיוני להתחבר מחדש באותה שיטת חיבור שנוצרה במקור.

### שלב 4 — אימות שהנתונים מגיעים

לאחר החיבור, המתן **30–60 דקות** ואז:
1. Metricool → **Analytics** → בחר את Facebook Page של UPE
2. בדוק שמופיעים: posts, reach, engagement
3. תעד את הנתונים הבסיסיים (baseline):
   - Reach שבועי
   - Engagement Rate

   - Impressions


## חלק ד׳ — המלצות טכניות נוספות ל-Metricool

1. ב-API של Facebook, מנשנים מוגבלים ל-3 לכל פוסט, ומומלץ לא לחרוג מ-9 hashtags — המספר האופטימלי הוא 2–3.
2. Facebook חושד בהתנהגות ספאמית אם מפרסמים תכנים תכופים מדי או זהים — שמור על 1/שבוע בשלב הראשון.
3. לניהול מרובה עמודים, מומלץ שאדמינים שונים יתחברו ל-Metricool — כך אם Facebook מבטל הרשאות, ההשפעה מינימלית.
4. אם מופיעה שגיאת Token: המשמעות היא שפרופיל ה-Admin המחובר איבד הרשאות — יש לבדוק הרשאות ולרענן את חיבור ה-Facebook Page.
