## חלק ב׳ — ניתוח קנבליזציה

הקנבליזציה הממשית שפוגעת בדירוג היא **same-intent overlap** — שני דפים ומעלה שעונים על אותה שאילתה עבור אותו משתמש.

### מטריצת קנבליזציה — UPE

| מונח | דפים חשודים | סוג הבעיה | המלצה ראשונית |
|------|-------------|-----------|---------------|
| הפקת אירועים לחברות + הפקות אירועים לחברות | `/הפקת-אירועי-חברה/` + `/הפקות-אירועים-לחברות/` + ייתכן `/הפקות-אירועים-עסקיים/` | 🔴 **קנבליזציה מתועדת** — 3 דפים, כוונה זהה | בחר דף ראשי; בדל או מזג את האחרים |
| הפקת נופש חברה + נופש חברה | `/נופש-חברה/` (URL יחיד לשני מונחים) | 🟡 **Overlap** — broader + narrower query על URL זהה | הוסף H2 ייעודי ל-broader query באותו דף |
| אירועי קונספט | `/אירוע-קונספט/` (יחיד לפי GSC) | 🟢 **ניקי** — עם עדכון Title/H1 | עדכן meta בלבד |

### פעולת אימות נדרשת לפני כל שינוי (⚠️ חובה):

```
GSC → Performance → Queries → הקלד מונח → Pages tab
→ כמה URLs מקבלים חשיפות?
  • URL אחד בלבד   = בעיית Title/Meta בלבד → עדכן meta tags
  • 2+ URLs        = קנבליזציה פעילה → בחר דף ראשי תחילה
```

השתמש ב-GSC Date Comparison כדי להשוות 3 חודשים אחרונים מול 3 חודשים קודמים — חפש דף שהקליקים/CTR שלו ירדו בעוד דף אחר צבר נראות לאותה query.

סימן אזהרה קלאסי: GSC מציג שני URLs מתחרים לאותה query באותו שבוע, כשעמדותיהם מתחלפות לאורך זמן.

## חלק ג׳ — Draft שינויים ממוקדים (לאישור לפני פרסום)

> **עיקרון 2026:** ה-Title Tag הוא המשתנה היחיד שאתה שולט בו לחלוטין ב-SERP. אם הוא לא מנצח קליקים, שום דירוג לא יציל אותו. Title צריך לא רק לכלול keywords — הוא צריך לגרום לאנשים לרצות ללחוץ.

> **פרמטרים טכניים:** Title tag: ייחודי, 50–60 תווים, שאילתה ראשית בתחילה. Meta description: 150–160 תווים.

## חלק ד׳ — מפת בדיקות לאחר שינוי (Post-Publish Tracking)

| פעולה | כלי | מועד בדיקה ראשון | מדד הצלחה |
|-------|-----|------------------|-----------|
