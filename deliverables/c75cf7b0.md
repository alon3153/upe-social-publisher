> **מה זה:** קוד, טקסט, והנחיות מוכנות לפרסום — CTA ספציפי בכל עמוד שירות. מחליף את "צרו קשר" הגנרי ב-CTA שמייצר ייחוס דיגיטלי מלא.

## 1. אסטרטגיה — למה זה עובד

רוב אתרי B2B מתייחסים ל-CTA כהחלטת עיצוב — צבע, מיקום, גודל. זו טעות. CTA הוא החלטת פוזיציונינג. הפער בין כפתור שמתעלמים ממנו לכפתור שמייצר לידים מגיע מתזמון נכון, ניסוח מדויק, והתאמה לשלב ההחלטה של הקונה.

CTAs מנצחים עוקבים אחרי כלל ה-3P: **Prominence** (גלוי בלי גלילה), **Promise** (הצהרת ערך ספציפית), ו-**Proof** (עדות הממוקמת בסמוך כדי להסיר היסוס).

כל עמוד משמעותי צריך CTA ראשי אחד ו-CTA משני אחד — עמודים ללא CTA או עם חמישה CTAs מתחרים שניהם ממירים גרוע.

לוואטסאפ יש open rate של ~98%, מה שהופך אותו לנכס השיווקי הדיגיטלי הרלוונטי ביותר עבור קהל ישראלי.

## 2. מיפוי CTA לפי עמוד שירות

> **הנחיה:** בכל עמוד — CTA ראשי אחד (כפתור ירוק/כחול בולט) + CTA משני אחד (link text). אין יותר מאלה.

| עמוד שירות | CTA ראשי | CTA משני | UTM Source |
|---|---|---|---|
| כנסים וקונגרסים | קבלו הצעה לכנס שלכם | דברו איתנו בוואטסאפ | `?utm_source=organic&utm_medium=service_page&utm_campaign=conference_cta` |
| אירועי תמריץ (Incentive Travel) | קבלו הצעה לטיול התמריץ | שאלו אותנו בוואטסאפ | `?utm_source=organic&utm_medium=service_page&utm_campaign=incentive_cta` |
| הפקת אירועים ארגוניים | קבלו הצעה לאירוע הבא | דברו עם מפיק | `?utm_source=organic&utm_medium=service_page&utm_campaign=corporate_cta` |
| ימי גיבוש | קבלו הצעה ליום גיבוש | שלחו פרטים בוואטסאפ | `?utm_source=organic&utm_medium=service_page&utm_campaign=teambuilding_cta` |
| כנסים בחו"ל / Destination Events | קבלו הצעה לאירוע בחו"ל | דברו עם מומחה יעדים | `?utm_source=organic&utm_medium=service_page&utm_campaign=destination_cta` |
| ניהול משתתפים | קבלו הצעה לניהול האירוע | שאלו אותנו בוואטסאפ | `?utm_source=organic&utm_medium=service_page&utm_campaign=management_cta` |

## 7. UTM Attribution Matrix — ייחוס דיגיטלי מלא

> זה הלב של הפתרון: **כרגע 0 לידים מיוחסים לדיגיטל.** עם המבנה הזה, כל ליד שמגיע מעמוד שירות אורגני יסומן אוטומטית.

| פרמטר | ערך | מטרה |
|---|---|---|
| `utm_source` | `google_organic` | הבחנה מ-paid |
| `utm_medium` | `service_page` | הבחנה מ-blog/home |
| `utm_campaign` | `conference_cta` / `incentive_cta` / `teambuilding_cta` / `destination_cta` | ייחוס לפי עמוד ספציפי |
| `utm_content` | `hero_cta` / `bottom_cta` | ייחוס לפי מיקום בעמוד |

**דוגמת URL מלאה:**
```
https://upe.co.il/quote?utm_source=google_organic&utm_medium=service_page&utm_campaign=conference_cta&utm_content=hero_cta
```

**הגדרה ב-GA4:** צרו Goal/Conversion Event בשם `quote_form_submit` + `whatsapp_click` עם event parameter `page_type=service`.
