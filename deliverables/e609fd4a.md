## חלק א׳ — הגדרת ה-Picklist הרשמי ב-Salesforce

### ✅ ערכי LeadSource המוסכמים ל-UPE (Restricted Picklist)

ה-LeadSource הוא picklist מסיבה — צריך להגדיר סט ערכים צמוד ולעצור שם. כל ערך נוסף שנציג יכול לבחור, וכל וריאנט בכתב חופשי, הופך לדוח עתידי שלא מסתכם.

| # | ערך ב-Picklist (מה שיופיע ב-SF) | ערוץ אמיתי | דוגמאות ספציפיות ל-UPE |
|---|---|---|---|
| 1 | `LinkedIn – Organic` | פוסט / מאמר / תגובה אורגנית | פוסט קייס סטאדי, מאמר thought leadership |
| 2 | `LinkedIn – Paid` | ממומן / InMail / Lead Gen Form | קמפיין לאירועי תאגיד Q1, InMail ל-HR |
| 3 | `YouTube` | וידאו / תיאור / קישור | ליד שמגיע דרך קישור בתיאור סרטון |
| 4 | `Organic Search` | Google / Bing – לא ממומן | מי שחיפש "חברת הפקת אירועים" |
| 5 | `Paid Search` | Google Ads / SEM | קמפיין ממומן בגוגל |
| 6 | `Referral – Client` | לקוח קיים שהפנה | המלצה ישירה מ-CMO לקוח |
| 7 | `Referral – Partner` | שותף עסקי / ספק / סוכן | פנייה דרך agency partner |
| 8 | `Event / Conference` | אירוע שבו UPE השתתפה | כנס HR, תערוכת IMEX |
| 9 | `Website – Direct` | טופס/צור קשר באתר, ללא UTM ידוע | Web-to-Lead ללא פרמטר |
| 10 | `Email – Outbound` | קמפיין אאוטבאונד שליחה ידנית | Cold outreach, Newsletter |
| 11 | `WhatsApp / Phone` | פנייה ישירה לטלפון/ווטסאפ | ליד שהתקשר ישיר |
| 12 | `Other – Specify in Notes` | כל שאר — **חובה להוסיף הערה** | |

> ⚠️ **חשוב:** `Other` מותר **רק** אם מצוין הסבר בשדה `Description` / `Lead Source Detail`. ללא הערה — הרשומה תחזור לנציג עם תזכורת אוטומטית.

## חלק ב׳ — שדה משני מומלץ: `Lead Source Detail` (Custom Field)

מומלץ להוסיף שדה מותאם אישית `Lead Source Detail` שיהיה ספציפי לקמפיין — כך שאם ה-LeadSource הוא "LinkedIn – Paid", ה-Detail יהיה שם הקמפיין הספציפי. כך ה-LeadSource מנורמל ומדרגי לדוחות.

**הגדרה טכנית:**
- **שם שדה:** `Lead_Source_Detail__c`
- **Type:** Text (255)
- **מיקום בלייאאוט:** מיד מתחת ל-`LeadSource`
- **חובה:** לא mandatory (אבל מומלץ בחינוך הצוות)

**דוגמאות שימוש ל-UPE:**

| LeadSource | Lead Source Detail |
|---|---|
| `LinkedIn – Paid` | `Campaign: CFO_Israel_Q3_2026` |
| `YouTube` | `Video: "Behind the Scenes – Incentive Trip Tokyo"` |
| `Organic Search` | `Keyword: הפקת כנסים בחו"ל` |
| `Referral – Client` | `Referred by: [שם לקוח]` |
| `Event / Conference` | `IMEX Frankfurt 2026` |

## חלק ג׳ — הגדרה טכנית ב-Salesforce (צעד-אחר-צעד לאדמין)

### שלב 1: עריכת ה-Picklist

לפני שמתחילים לרשום מקורות, יש לוודא שערכי ה-picklist תואמים לערוצים האמיתיים. נווט ל: **Setup ← Object Manager ← Lead ← Fields & Relationships ← Lead Source ← Values**, ולחץ **New** להוספת ערך או **Edit** לשינוי ערך קיים.

```
Setup → Object Manager → Lead → Fields & Relationships → Lead Source
→ [Deactivate] כל ערך ישן שלא בשימוש
→ [New] הוספת ערכי UPE לפי הטבלה למעלה
→ סמן "Restricted Picklist" — מונע הקלדה חופשית
```

### שלב 2: הגדרת Restricted Picklist (קריטי!)

יש לנעול את LeadSource כ-Restricted Picklist ולאמן את צוות המכירות והשיווק להשתמש רק בערכים הסטנדרטיים. יש לבצע ביקורת נתונים חודשית כדי לזהות ולתקן סטיות.

### שלב 3: Flow אוטומטי — מילוי LeadSource בלידים מ-Web-to-Lead

יש לאכלס את LeadSource בעת יצירת הרשומה — מ-Web-to-Lead, מהטופס, או מאוטומציה — ולא להסתמך על נציג שייזכר. שדה שמולא בעת המקור הוא מדויק; שדה שמולא מזיכרון שלושה ימים לאחר מכן הוא ניחוש.

**Flow להגדרה (Salesforce Flow Builder):**

```
Trigger: Record Created — Object: Lead
Condition: LeadSource IS NULL
AND
Web_Form_Source__c (hidden field from UTM) IS NOT NULL

Action: Update Record
  LeadSource = [MAP from utm_source]:
    "linkedin"  → "LinkedIn – Organic"
    "linkedin_paid" → "LinkedIn – Paid"
    "youtube"   → "YouTube"
    "google"    → "Organic Search"
    "google_cpc" → "Paid Search"
    (default)   → "Website – Direct"
```

### שלב 4: UTM Parameters — תשתית הייחוס

פרמטרי UTM (utm_source, utm_medium, utm_campaign, utm_content, utm_term) לוכדים הקשר קמפיין מתנועת אינטרנט. אם לא לוכדים אותם בשליחות טפסים וממפים לשדות Salesforce — מאבדים נתוני ייחוס.

**טבלת UTM Standards ל-UPE:**

| ערוץ | utm_source | utm_medium | utm_campaign | LeadSource שיווצר |
|---|---|---|---|---|
| LinkedIn Organic | `linkedin` | `social` | `organic_post` | `LinkedIn – Organic` |
| LinkedIn Paid | `linkedin` | `paid_social` | `[campaign_name]` | `LinkedIn – Paid` |
| YouTube | `youtube` | `video` | `[video_name]` | `YouTube` |
| Google Organic | `google` | `organic` | *(none)* | `Organic Search` |
| Google Ads | `google` | `cpc` | `[campaign_name]` | `Paid Search` |
| Email Campaign | `email` | `email` | `[campaign_name]` | `Email – Outbound` |

> 📌 **כלל ברזל:** כל קישור יוצא מ-UPE (פוסט, תיאור YouTube, חתימת אימייל, ביו לינקדאין) — חייב לכלול UTM. ללא UTM, הליד יירשם כ-`Website – Direct` ויאבד.

### שלב 5: וידוא שה-LeadSource עובר להזדמנות (Opportunity)

מיפוי שדות הוא קריטי להוכחת ROI. אם נתוני LeadSource לא עוברים להזדמנות, מאבדים את היכולת לייחס הכנסה לקמפייני שיווק.

```
Setup → Object Manager → Lead → Fields & Relationships → Lead Source
→ "Map Lead Fields" → וודא שמוגדר מיפוי ל:
   Contact.LeadSource ✓
   Opportunity.LeadSource ✓  (שדה custom אם לא קיים)
```

## חלק ד׳ — דשבורד ייחוס ב-Salesforce (הגדרת דוח בסיסי)

### דוח 1: לידים לפי מקור (חודשי)

```
Report Type: Leads
Group By: Lead Source
Columns: 
  - Lead Source
  - Count of Leads
  - Count of Converted Leads  
  - Conversion Rate %
  - Won Opportunities (via Opportunity field)
Filter: Created Date = THIS MONTH / LAST QUARTER
```

### דוח 2: "LeadSource Blank" — ניטור אי-מילוי

```
Report Type: Leads
Filter: Lead Source EQUALS (blank)
         AND Created Date = LAST 30 DAYS
Columns: Lead Owner, Created Date, Company, Email
Action: שלח אוטומטית לצוות כל שני בבוקר
```

> 🔴 **יעד:** אחוז לידים עם LeadSource ריק ≤ 5% תוך 30 יום מההדרכה.

### 5.3 — Validation Rule להגדרה ב-Salesforce (מניעת שמירה ללא ייחוס)

כדי להבטיח שנאספים הנתונים הנכונים, חשוב לוודא שהשדות הנכונים הם mandatory ושהולידיישן הנכון קיים.

```apex
/* Validation Rule: Require LeadSource on Manual Creation */
Rule Name: Require_LeadSource_If_Manual
Active: TRUE

Error Condition Formula:
AND(
  ISBLANK(LeadSource),
  NOT($System.OriginatingSystemName = "Web"),
  NOT(ISPICKVAL(Status, "Converted"))
)

Error Message: 
  "חובה לבחור מקור ליד (Lead Source). 
   אם אינך בטוח, בחר 'Other' והוסף הערה. 
   ייחוס נכון = ROI שאנחנו יכולים להוכיח."

Error Location: Lead Source field
```
