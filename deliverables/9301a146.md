## 🔍 הקשר ובעיה

כרגע, לידים נכנסים דרך טופס יצירת קשר/בקשת הצעת מחיר באתר UPE — אך **Salesforce מציג 0 לידים דיגיטליים** עם ייחוס ערוץ. הסיבה: ללא מנגנון לכידה, ה-CRM מסתיים בייחוס גנרי של "Web" לרוב הנכנסים. בנוסף, ייחוס self-reported מגלה ש-30%–50% מה-pipeline מקורו בערוצים שאינם נראים לאנליטיקס הדיגיטלי — כולל המלצות פה לאוזן, לינקדאין, אירועי תעשייה, וואטסאפ ועוד.

100% מהכניסות מ-WhatsApp, Slack ו-Discord מגיעות ללא נתוני referral כלל — ונרשמות כ-"direct traffic". ב-UPE, שבה הרוב המכריע של העסקאות מגיע דרך רשתות קשרים ועולמות B2B, פער זה קריטי.

**הפתרון:** הוספת שדה `איך הגעת אלינו?` לטופס הצעת מחיר/יצירת קשר, בשילוב שדות hidden לאוטומציה — הוספת self-reported attribution לטפסים high-intent היא צעד ראשון מומלץ לפני שמוסיפים כלי attribution ייעודי.

### 2C — JavaScript: UTM Persistence (חובה — ראה הסבר למטה)

```javascript
/**
 * UPE Attribution JS — UTM Persistence + Hidden Field Population
 * ---------------------------------------------------------------
 * DRAFT FOR APPROVAL — לא לדפלוי לפני בדיקה
 *
 * הסיבה לשמירה ב-sessionStorage:
 * ליד שמגיע עם UTM בעמוד הנחיתה, אך ממלא טופס בעמוד אחר —
 * מאבד את ה-UTM אם לא שומרים אותם. שכבה זו פותרת את הבעיה.
 */

(function () {
  'use strict';

  // ── 1. קרא UTM מה-URL הנוכחי
  function getParam(name) {
    var url = new URLSearchParams(window.location.search);
    return url.get(name) || '';
  }

  // ── 2. שמור ב-sessionStorage אם קיים ב-URL
  var params = ['utm_source', 'utm_medium', 'utm_campaign', 'utm_content', 'utm_term'];
  params.forEach(function (p) {
    var val = getParam(p);
    if (val) sessionStorage.setItem('upe_' + p, val);
  });

  // ── 3. שמור Referrer + Landing Page בביקור הראשון בלבד
  if (!sessionStorage.getItem('upe_landing_page')) {
    sessionStorage.setItem('upe_landing_page', window.location.pathname);
  }
  if (!sessionStorage.getItem('upe_referrer_url') && document.referrer) {
    sessionStorage.setItem('upe_referrer_url', document.referrer);
  }

  // ── 4. כאשר DOM מוכן — מלא שדות hidden
  document.addEventListener('DOMContentLoaded', function () {
    params.forEach(function (p) {
      var el = document.getElementById('upe_' + p);
      if (el) el.value = sessionStorage.getItem('upe_' + p) || '';
    });

    var lp = document.getElementById('upe_landing_page');
    if (lp) lp.value = sessionStorage.getItem('upe_landing_page') || '';

    var ref = document.getElementById('upe_referrer_url');
    if (ref) ref.value = sessionStorage.getItem('upe_referrer_url') || '';
  });

})();
```

> **למה זה קריטי?** פרמטרי UTM חייבים להתמיד לאורך כל הסשן — יש לשמור אותם ב-sessionStorage או cookie ראשוני בטאץ' הראשון, ולאפשר לטופס לקרוא מ-storage ולא מה-URL הנוכחי. שינוי זה בלבד מכפיל בדרך כלל את שיעור הלידים עם ייחוס.

## 🧪 PART 5 — A/B Test Plan (אופציונלי — לשיקול)

מומלץ להריץ A/B test עם פרמטרים ברורים כדי למדוד את השפעת השדה על שיעור ההמרה של הטופס. מדד ראשי: Form conversion rate.

| גרסה | תיאור | KPI |
|---|---|---|
| **Control** | הטופס הנוכחי ללא שדה | Baseline conversion rate |
| **Variant A** | שדה optional — radio buttons | Δ conversion rate vs. control |
| **Variant B** | שדה required — dropdown | Δ conversion rate + fill rate |

> 💡 **המלצה:** התחל עם **optional** (variant A). כאשר השדה optional, כ-30% מהמשיבים אינם ממלאים — אך זה עדיף על אובדן לידים מ-required field שעלול להרתיע.

## ⚠️ מגבלות ידועות — לשקיפות

אנשים לעיתים קרובות אינם זוכרים במדויק כיצד שמעו לראשונה על עסק, ותשובותיהם עשויות להיות מושפעות מ-recency bias — מחזק נקודות מגע אחרונות יותר. כמו כן, המרת לקוח מתרחשת בדרך כלל לאחר נקודות מגע מרובות, כך שחלק מהערוצים עשויים לא להיות מיוצגים.

**הפתרון:** עקוב אחר תשובות ה-self-reported ב-CRM וצור תצוגת ייחוס מקבילה — self-reported מול מודל דיגיטלי — לניתוח השוואתי.
