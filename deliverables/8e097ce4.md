<a name="1-strategy"></a>
## 1. אסטרטגיה ועקרונות מנחים

### הבעיה שאנחנו פותרים
גולשים אורגניים מגיעים לדפי השירות של UPE — ויוצאים **ללא שום פעולה מזוהה**. אפס לידים מיוחסים לדיגיטל, למרות תנועה אורגנית קיימת.

### העיקרון המנחה (2026)
CTA גנרי מפספס כי הוא לא תואם את הכוונה של המבקר. יש להתאים את הקריאה לפעולה לפרסונה, לשלב במשפך ולסוג הדף — התאמה כזו מגדילה המרות ללא הגדלת תנועה.

### חוקי הטופס
הפחתת שדות מ-7+ ל-3-5 מגדילה השלמות בין 25% ל-120%. לכן הטופס של UPE יכיל **4 שדות בלבד** בשלב ראשון.

העיקרון הוא progressive profiling — לתפוס מינימום מידע ראשוני, ולאסוף פרטים נוספים בשלב המשך.

### אמינות ו-trust signals
האלמנטים הממירים ביותר בדפי לידים: עדויות לקוחות עם שם מלא וחברה, מדדי social proof ספציפיים ('1,500+ אירועים'), ולוגואים של לקוחות מוכרים. יש למקם לפחות אחד מהם צמוד לטופס עצמו — זה מוריד נטישת טפסים.

### אינטגרציית Salesforce
טופס Web-to-Lead ב-Salesforce לוכד מידע ישירות ל-CRM אוטומטית — ללא הזנה ידנית, ומבטיח שהלידים מתועדים מיידית.

יש לאכלס את שדה LeadSource בזמן יצירת הרשומה (דרך Web-to-Lead או אוטומציה) ולא להסתמך על נציג שיזכור אחרי שלושה ימים — שדה שמולא במקור הוא מדויק; שדה שמולא מהזיכרון הוא ניחוש.

## 2. CTA ברכיבי הדף — עיצוב ותוכן (×3 דפים)

### עקרון מיקום
כל דף מקבל **3 נקודות CTA**:
- **Above the fold** — Hero section (מקסימום חשיפה)
- **אמצע הדף** — לאחר הצגת השירות
- **Bottom sticky / footer** — רשת ביטחון לגולשים שהגיעו לסוף

---

## 3. הטופס הקצר — שדות, UX ועיצוב

### 4 שדות בלבד (Phase 1)

| # | שדה | סוג | חובה? | placeholder |
|---|-----|-----|-------|------------|
| 1 | שם מלא | Text | ✅ | "ישראל ישראלי" |
| 2 | אימייל עסקי | Email | ✅ | "israel@company.co.il" |
| 3 | שם החברה | Text | ✅ | "חברה בע״מ" |
| 4 | סוג האירוע | Dropdown | ✅ | "בחרו סוג אירוע ▼" |

**ערכי Dropdown — "סוג האירוע":**
```
▸ אירוע עסקי / כנס חברה
▸ ועידת לקוחות / גאלה
▸ טיול תמריץ לעובדים
▸ השקת מוצר / Brand Event
▸ אחר — אשמח לפרט
```

### שדות hidden (לא גלויים למשתמש, מועברים ל-Salesforce)
```
lead_source      = "Web"
lead_source_detail = [URL הדף — מועבר אוטומטית]
campaign_id      = [UTM campaign אם קיים]
page_type        = [הפקת-אירועים / ארגון-כנסים / טיולי-תמריץ]
```

### כפתור Submit
```
[ קבלו הצעה לאירוע שלכם — חינם ← ]
```
*(טקסט מותאם לפי דף — ראה טבלה למטה)*

## 4. קוד HTML מוכן לשילוב (Web-to-Lead)

> ⚠️ **הוראות לפני שימוש:**
> 1. הכנסו ל-Salesforce Setup → Web-to-Lead → Generate form
> 2. העתיקו את ה-`oid` (Organization ID) ואת ה-`retURL` שמייצר Salesforce
> 3. החליפו את הפלייסהולדרים `[YOUR_ORG_ID]` ו-`[YOUR_THANK_YOU_URL]`
> 4. עדכנו את `[FIELD_ID_EVENT_TYPE]` ל-API name של השדה המותאם אישית שיצרתם

<script>
(function () {
  'use strict';

  // 1. Populate UTM + page source hidden fields
  function getParam(name) {
    var url = new URL(window.location.href);
    return url.searchParams.get(name) || '';
  }

  document.getElementById('upe_page_source').value   = window.location.pathname;
  document.getElementById('upe_utm_campaign').value  = getParam('utm_campaign');
  document.getElementById('upe_utm_medium').value    = getParam('utm_medium');
  document.getElementById('upe_utm_source').value    = getParam('utm_source');

  // 2. Dynamic CTA button text per page slug
  var pageSlugMap = {
    'hafakat-eiru'      : 'קבלו הצעה לאירוע שלכם ←',   // הפקת-אירועים-עסקיים
    'irgun-knasim'      : 'קבלו הצעה לכנס שלכם ←',      // ארגון-כנסים
    'tiyulei-tamritz'  : 'קבלו הצעה לטיול התמריץ ←'    // טיולי-תמריץ-לחברות
  };
  var path = window.location.pathname;
  var btn  = document.getElementById('upe-submit-btn');
  for (var slug in pageSlugMap) {
    if (path.indexOf(slug) !== -1) {
      btn.textContent = pageSlugMap[slug];
      break;
    }
  }

  // 3. Inline validation (Hebrew error messages)
  var form = document.getElementById('upe-w2l-form');
  form.addEventListener('submit', function (e) {
    var valid = true;
    var fields = [
      { id: 'upe_name',       msg: 'אנא הזינו שם מלא' },
      { id: 'upe_email',      msg: 'אנא הזינו כתובת אימייל תקינה' },
      { id: 'upe_company',    msg: 'אנא הזינו שם חברה' },
      { id: 'upe_event_type', msg: 'אנא בחרו סוג אירוע' }
    ];
    fields.forEach(function (f) {
      var el  = document.getElementById(f.id);
      var err = el.nextElementSibling;
      if (!el.value.trim() || (el.type === 'email' && !el.validity.valid)) {
        err.textContent = f.msg;
        el.classList.add('upe-field-error');
        valid = false;
      } else {
        err.textContent = '';
        el.classList.remove('upe-field-error');
      }
    });
    if (!valid) e.preventDefault();
  });

})();
</script>

<a name="6-salesforce"></a>
## 6. מיפוי שדות Salesforce — Web-to-Lead

ב-Salesforce Setup יש להגדיר Lead Assignment Rules לניתוב לידים חדשים לתור המכירות הנכון, ו-Auto-Response Rules כך שהלקוח הפוטנציאלי מקבל מייל אישור מיידי.

| שדה בטופס | API Name ב-Salesforce | ערך / מקור | הערות |
|-----------|----------------------|------------|-------|
| שם מלא | `name` (standard) | קלט משתמש | First+Last אחיד |
| אימייל | `email` (standard) | קלט משתמש | ולידציה בצד לקוח |
| שם חברה | `company` (standard) | קלט משתמש | — |
| סוג אירוע | `Event_Type__c` (custom) | קלט משתמש | Picklist — יצרו בהגדרות |
| **Lead Source** | `lead_source` (standard) | **`Web`** (hardcoded) | **קריטי — P0** |
| מקור עמוד | `00N_UPE_PageSource` (custom) | `window.location.pathname` | לדיווח attribution |
| UTM Campaign | `00N_UPE_UTMCampaign` (custom) | `utm_campaign` param | לקמפיינים עתידיים |
| UTM Medium | `00N_UPE_UTMMedium` (custom) | `utm_medium` param | — |
| UTM Source | `00N_UPE_UTMSource` (custom) | `utm_source` param | — |

### Lead Assignment Rule (מומלץ)
```
IF  LeadSource = "Web"
AND Event_Type__c IN [כל הערכים]
THEN → Assign to: [תור/משתמש UPE המטפל בלידים נכנסים]
     → Send notification email: YES
```

מומלץ לשמור את ה-Lead Source picklist לערכי ערוץ בלבד (קצר ומוסכם), ולהוסיף שדה מותאם אישית לפרטים נוספים: קמפיין, עמוד נחיתה ומסלול.
