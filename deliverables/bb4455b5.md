# 📋 מסמך הפעלה: API Credits Benefit — OpenAI (ChatGPT Pro / Business)

**סיווג:** פעולה אדמינית פנימית | **בעלים:** אלון | **סטטוס:** טיוטה לאישור בלבד

---

## רקע ועובדות מאומתות

ב-28 באוקטובר 2026 הכריזה OpenAI על הטבה חדשה: מנויי ChatGPT Pro ו-Business זכאים לקבל קרדיטים חינמיים לשימוש ב-API של OpenAI — עד $500 לחודש.

ChatGPT subscription ו-OpenAI API הם שני מוצרים נפרדים עם חיוב נפרד — ה-"גשר" היחיד ביניהם הוא הטבת ה-API Credits שנכנסה לתוקף ב-28 באוקטובר 2026 לחברי Pro ו-Business בלבד.

מנויי ChatGPT Pro מקבלים $100, $200 או $500 לחודש (בהתאם לרמת התוכנית שלהם), ו-Business Workspaces מקבלים $20 או $100 למושב — עד מקסימום $500 לסביבת עבודה.

הקרדיטים מנוצלים ראשונים (לפני קרדיטים שנרכשו), פגים עם כל מחזור חיוב, ואינם ניתנים לצבירה.

---

## ✅ תנאי זכאות — נדרש לאמת לפני הפעלה

הזכאות מחייבת: מנוי Pro או Business בגיל לפחות 7 ימים, כאשר אותו אדם הוא הבעלים גם של מנוי ChatGPT וגם של ארגון ה-API המקושר.

חובה להשתמש באותה כתובת אימייל עבור חשבון ה-ChatGPT וחשבון ה-API Platform.

נדרשת הרשאת ניהול חיוב בארגון ה-API — תפקיד Billing מותאם בלבד אינו מספיק; נדרשת בעלות (Owner) בארגון ה-API.

---

## 🔧 הוראות הפעלה שלב-בשלב

> ⚠️ **שים לב:** ניתן להפעיל את ההטבה בשתי דרכים — מתוך ChatGPT (Pro) **או** מתוך API Platform (Business/Pro). מוצגות שתי הדרכים.

---

### דרך א׳ — הפעלה מתוך ChatGPT (מומלץ לחשבון Pro)

1. **פתח Settings → Billing** ב-ChatGPT.
2. **עיין בארגון ה-API** שיקבל את הקרדיטים ואמת שהוא הנכון.
3. אשר את ההקמה / לחץ **Claim**.
4. **פתח את הגדרות ה-Billing ב-API Platform** ואמת שהקרדיטים מופיעים בארגון המקושר.

---

### דרך ב׳ — הפעלה מתוך API Platform (מומלץ ל-Business Workspace)

1. **היכנס ל-API Platform** עם כתובת האימייל המשויכת למנוי ChatGPT הזכאי.
2. **בחר את ארגון ה-API** שאתה מחזיק בבעלותו ושיקבל את הקרדיטים.
3. **פתח Billing** ואתר את "API credits benefit".
4. **בחר את מנוי ChatGPT / Business Workspace** הרלוונטי לקישור.

---

### אחרי ההפעלה

לאחר ההפעלה, OpenAI תנפיק קרדיטים חדשים אוטומטית בכל חידוש מנוי — אין צורך לחזור על התהליך מדי חודש.

הארגון ישתמש בקרדיטים החינמיים לפני שימוש בקרדיטים שנרכשו.
