## ✅ רשימת בדיקה לפני הפרסום

לפני הפרסום: בדוק כל Schema ב-Google Rich Results Test ואמת שאין שגיאות `required properties`.

שים לב: אם יש פלאגין (Rank Math / Yoast) שכבר מוסיף LocalBusiness Schema — **אל תכפיל בלוקים**. גוגל ינסה לפתור קונפליקט ולעיתים ידחה את שניהם. השתמש בשיטת יישום אחת בלבד לכל האתר.

- [ ] **תוכן הדף** — ה-H1 מופיע פיזית ב-`<body>` (לא רק בtitle)?
- [ ] **Title ≤ 55 תווים** — ספרו תווים בכלי כמו Pixel Width Checker
- [ ] **Meta description ≤ 155 תווים** — בדיקה ב-Screaming Frog
- [ ] **`aggregateRating`** — מלאו ערכים מ-GBP בלבד (אחרת הורידו את הבלוק)
- [ ] **`sameAs` URLs** — ודאו שה-URLs של LinkedIn / Facebook נכונים
- [ ] **Organization `@id`** — צריך להיות זהה בכל 5 הדפים (עוגן גרף האישות)
- [ ] **Rich Results Test** — הריצו כל URL לאחר פרסום

**הפוטנציאל:** דפים עם structured data תקין יכולים להניב עלייה של 30%–82% ב-CTR אורגני לפי case studies של גוגל עצמו.
