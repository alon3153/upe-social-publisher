## 1. אסטרטגיה ורציונל {#strategy}

**למה זה P1:**
82% ממנהלי המכירות B2B מאמינים שהפניות מייצרות את הלידים האיכותיים ביותר מכל מקור. שיווק הפניות מייצר פי 3–5 שיעורי המרה גבוהים יותר מכל ערוץ שיווקי אחר. 42% ממנהלי CMO B2B מדרגים Word of Mouth כערוץ המוביל שמכניס ספקים לרשימת הבחינה שלהם — לעומת 2% בלבד לפרסום ממומן ו-2% לפנייה קרה.

**מה עובד בפוסטים בלינקדאין 2026:**
LinkedIn מקדמת כיום תוכן "ידע וייעוץ" מאנשים שחולקים מומחיות אמיתית; אלגוריתם הפיד נבנה מחדש כדי להפחית תוכן ויראלי אך חסר ערך ולחזק פוסטים ממומחי תוכן. פוסטי Carousel (מסמכי סיפון) הם פורמט ה-LinkedIn בעל הביצועים הגבוהים ביותר ב-2026, עם פי 3.5 יותר מעורבות מפוסטי טקסט בלבד. פוסטים עם המלצות מייצרים עד 180% יותר תגובות בלינקדאין, כאשר 92.4% מהאנשים סומכים על ביקורות.

**מבנה המנגנון (FLYWHEEL):**
```
אירוע מוצלח → ציטוט ממשי מהלקוח → Spotlight פוסט (tag) → חשיפה לרשת הלקוח → DM/בקשת הפניה → ליד חדש → אירוע מוצלח → ...
```

## 2. תהליך ה-Spotlight מקצה לקצה {#process}

```
שבוע 1 לאחר האירוע  →  שבוע 2               →  שבוע 3          →  שבוע 3–4
─────────────────────────────────────────────────────────────────────────────────
Account Manager       Content Manager         עיצוב              פרסום + הפניה
שולח WhatsApp/מייל   מגבש ציטוט + draft פוסט   מייצר slide deck    פוסט פורסם
לבקשת ציטוט          ושולח ללקוח לאישור        LinkedIn + Reel     DM הפניה נשלח
```

**חוקי ברזל:**
- ✅ הציטוט חייב להיות מאושר בכתב ע"י הלקוח לפני פרסום
- ✅ לקוח מתויג בשמו ובפרופיל LinkedIn שלו
- ✅ פוסט מועבר ללקוח מראש (48 שעות) — הוא ישתף מיוזמתו
- ✅ בקשת הפניה נשלחת רק לאחר שהלקוח לייק/שיתף את הפוסט
- ❌ לא מפרסמים ללא אישור מפורש בכתב

## 10. מפרט עיצובי {#design-spec}

פוסטי מסמך מרובי תמונות מניבים שיעור מעורבות של 6.60% — הגבוה מכל פורמט — כאשר הביצועים הטובים ביותר מגיעים לסיפונים עם 8–10 שקופיות עם סיפור ויזואלי ברור.

```
LinkedIn Carousel Specs (2026):
├── Format: PDF document post (NOT image slides — PDF gets more reach)
├── Dimensions: 1080 x 1080px (square) or 1080 x 1350px (portrait — preferred)
├── Slides: 7 slides (sweet spot: 6–9)
├── Font: UPE brand font | Min 24pt body | 40pt+ headlines
├── Colors: UPE brand palette (פלטה ממותגת)
├── Slide 1: MUST hook within 3 seconds — client quote fragment or event photo
├── Last slide: ALWAYS CTA + contact info + logo
└── File size: Under 10MB

Instagram Reel Specs:
├── Duration: 30–45 seconds
├── Dimensions: 1080 x 1920px (9:16)
├── Captions: Auto-generated + manually edited (accessibility + reach)
├── Cover frame: Branded still with client quote fragment
└── Audio: Licensed music or UPE branded audio track

Instagram Static Carousel (backup):
├── Dimensions: 1080 x 1080px
├── Slides: 5–7
└── Consistent brand frame across all slides
```
