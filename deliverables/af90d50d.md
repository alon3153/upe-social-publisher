### 🎯 למה זה חשוב — בשלושה משפטים

כל ליד שנכנס ל-Salesforce ללא ערך מקור מדויק הוא ליד עיוור.
רוב הצוותים לא סובלים מבעיית מעקב — הם סובלים מבעיית אמון: כשנתוני מקור הליד לא מדויקים או עקביים, אי-אפשר לקשור pipeline והכנסה למקורות הנכונים.
Picklist מסודר נותן תצוגת ערוץ אמינה. ללא ממשמעת, הוא הופך לרעש תוך רבעון אחד.

---

### 📋 ה-Picklist הסגור — שבעה ערכים בלבד

ה-Lead Source הוא picklist מסיבה — יש להגדיר סט קטן ומדויק של ערכי ערוץ ולעצור שם. כל ערך נוסף שנציג יכול לבחור, וכל וריאנט טקסט חופשי, הוא דוח עתידי שלא מסתכם. פחות ערכים, נקיים יותר — עדיפים על רשימה ארוכה שאיש לא מסכים עליה.

| # | ערך Picklist (כפי שיופיע ב-SF) | הגדרה תפעולית | מי ממלא? |
|---|---|---|---|
| 1 | `Google Organic` | ליד שמצא את UPE דרך חיפוש אורגני ב-Google (לא ממומן) | מולא אוטומטית דרך Web-to-Lead / הנציג |
| 2 | `Web (Form)` | טופס יצירת קשר / בקשת הצעה ישירות מהאתר (ללא זיהוי ערוץ ספציפי) | מולא אוטומטית דרך Web-to-Lead |
| 3 | `LinkedIn` | פנייה שמקורה ב-LinkedIn — organic, InMail, פוסט, מודעה מ-LinkedIn | הנציג |
| 4 | `Advertisement (Paid)` | כל קמפיין ממומן שאינו LinkedIn — Google Ads, Meta, Display, Retargeting | מולא אוטומטית / הנציג |
| 5 | `Word of Mouth` | המלצה אישית ממכר, שותף, אירוע רשת (לא לקוח קיים) | הנציג |
| 6 | `Existing Customer` | פנייה מלקוח שעבד עם UPE בעבר — חידוש, הרחבה, הפניה מתוכו | הנציג |
| 7 | `Other` | **⚠️ חייב הערה** — ראה כללי שימוש למטה | הנציג |

> **כלל ברזל:** כל ליד יכול לשאת ערך Lead Source אחד בלבד. בחר את המקור **הראשון** שבו הליד יצר קשר עם UPE.

### ⚙️ כללי שימוש — שאלות ותשובות

**ש: ליד שמצא אותנו ב-Google ואז מילא טופס — מה אסמן?**
→ `Google Organic`. הטופס הוא אמצעי ההגעה, לא המקור.

**ש: לקוח ישן שחזר אחרי שלוש שנים ופנה דרך LinkedIn?**
→ `Existing Customer`. קשר קודם מנצח ערוץ נוכחי.

**ש: קיבלתי שיחה קרה שאני בדעתי להפוך לליד — מה אסמן?**
→ `Other` + הערה: "Cold Call – [שם הנציג] – [תאריך]".

**ש: מה עושים עם `Other`?**
→ שדה ה-Notes **חובה** מלא. מלא את Lead Source ברגע יצירת הרשורד, לא שלושה ימים אחר-כך מהזיכרון — שדה שמולא במקור הוא מדויק; שדה שמולא מהזיכרון הוא ניחוש.

### 📊 איך המידע הזה משמש את הצוות

שדה ה-Lead Source מציין מאיפה הגיעו הלידים — מה שמאפשר לזהות אילו ערוצים מייצרים את מספר הלידים הגבוה ביותר, ובהמשך אילו מייצרים את ההכנסה הגבוהה ביותר.

בהקשר UPE:
- נוכל לזהות אם **Word of Mouth** מניב קצב סגירה גבוה יותר מ-**LinkedIn**
- נוכל להצדיק (או לבטל) תקציב קמפיין על בסיס נתוני `Advertisement (Paid)` אמיתיים
- נוכל לזהות לקוחות חוזרים (`Existing Customer`) ולעדכן את אסטרטגיית ה-retention

> **חשוב:** נתוני Lead Source הם **היפותזות שמחכות לאימות**. אין לטעון שיפור KPI ללא בסיס נתונים מדוד ממשי ותקופות השוואה תואמות.

### שלב 1 — גיבוי נתונים קיימים


### שלב 2 — עדכון הפיקליסט

נווט אל: **Setup → Object Manager → Lead → Fields and Relationships → Lead Source**. גלול למטה עד לרשימת ערכי ה-Picklist. הוסף את הערכים החדשים מהרשימה שלך, ואת הערכים הישנים — שייך אליהם. השתמש בכלי "Replace" להחלפה אחת-לאחת. לאחר כל החלפה, וודא שהערך הישן מושבת (Deactivate).

**ערכים לשמור פעילים:**

```
Google Organic
Web (Form)
LinkedIn
Advertisement (Paid)
Word of Mouth
Existing Customer
Other
```

**ערכי ברירת-מחדל של Salesforce שיש להשבית:**

```
Web → Replace with: Web (Form) then Deactivate
Partner or Reseller → Deactivate
Internal → Deactivate
(כל שאר ערכי default שלא ברשימה הנ"ל)
```

---

### שלב 3 — הפיכת הפיקליסט ל-Restricted (סגור)

ב-Salesforce, ניתן להגדיר את שדה ה-Lead Source כ-Restricted כדי לשמור על ערכים עקביים.

```
Setup → Object Manager → Lead → Fields and Relationships → Lead Source
→ Edit → ✅ "Restrict picklist to the values defined in the value set"
→ Save
```

> **⚠️ הערת אדמין:** הגדרת Restricted Picklist עלולה לגרום לשגיאות סנכרון עם Account Engagement / Pardot, מכיוון ש-AE מאכלס את שדה המקור באופן אוטומטי. אם לא מגדירים Restricted, השדה פתוח לקבל כל ערך, וערכים שאינם ברשימה עלולים להופיע ולפגוע בעקביות. יש לבחור בהתאם לאינטגרציות הקיימות ב-UPE.

### שלב 4 — הגדרת Validation Rule (חובת הערה ל-Other)

```
Rule Name: LeadSource_Other_Requires_Note
Object: Lead
Error Condition Formula:

AND(
  ISPICKVAL(LeadSource, "Other"),
  ISBLANK(Description)
)

Error Message: "כשמקור הליד הוא 'Other', חובה למלא הסבר בשדה Description/Notes."
Error Location: Description
```
