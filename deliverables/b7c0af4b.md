## ו. כללי הפקה — "Anti-Script Rules" לצוות

ה-Hook חי בשנייה הראשונה עד שתיים, וזה מה שקובע הכל. אם לא מרוויחים את השנייה השנייה — הצופה עוזב והאלגוריתם לא מרחיב את ה-Reach. Hook הוא הבטחה + הפרעת דפוס: אמרו מה הם עומדים לקבל עם תנועה חזותית או מילולית שעוצרת את הגלילה.

| ✅ עשה | ❌ אל תעשה |
|---|---|
| פתח **בתנועה** — הלך, הצבע, Cut מהיר | "היי, שלום, ברוכים הבאים ל-UPE" |
| דבר לאדם אחד — "אתה מארגן כנס?" | נאום כללי לכולם |
| רעש אמיתי של האולם / הבנייה | מוזיקת רקע גנרית בלבד |
| כיתוב בעברית על המסך (Auto + ידני) | ווידאו ללא כיתוב |
| קובץ גולמי לשני הפלטפורמות | Watermark מ-TikTok לאינסטגרם |
| Caption שונה לכל פלטפורמה | Copy-paste זהה |
| שאלה אחת בסוף | אין CTA |

## ח. Cross-Posting SOP — 5 שלבים

```
1. צלמו בפורמט אנכי 9:16 (1080×1920px) — קובץ גולמי
2. ערכו (CapCut / Premiere) → ייצוא נקי ללא Watermark
3. עלו ל-TikTok ראשון → הוסיפו Caption TikTok + 3-5 האשטאגים
4. המתינו 24–48 שעות
5. עלו את הקובץ הגולמי (לא מ-TikTok!) לאינסטגרם → Caption IG שונה + 
   החליפו מוזיקת TikTok בספריית Instagram
```

> TikTok, Instagram, YouTube, Facebook, X ו-LinkedIn לא חולקים fingerprints תוכן זה עם זה — אין זיהוי תוכן כפול בין פלטפורמות. הבעיה היחידה: Watermark ואיכות.
