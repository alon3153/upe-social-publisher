## PART D — Validation Rule מוצע ב-Salesforce (לאדמין)

> **מטרה:** לחסום שמירת רשומת ליד ללא Lead Source, ולחייב הוספת הערה כש-`Other` נבחר.

### Rule 1 — חובת מילוי שדה Lead Source

**שם ה-Rule:** `LeadSource_Required`

```
/* Validation Rule — Error if LeadSource is blank */
AND(
  ISBLANK(LeadSource),
  NOT(ISNEW())   /* מאפשר יצירה ראשונית ע"י automation לפני שמירה ידנית */
)
```

**Error Message (Hebrew):**
```

```

**Field:** `Lead Source` | **Location:** Top of page

### Rule 2 — חובת הערה כש-Other נבחר

**שם ה-Rule:** `Other_Requires_Description`


**Error Message (Hebrew):**
