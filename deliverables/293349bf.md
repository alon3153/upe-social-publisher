### ✅ H-48 Checklist: 12 Steps Before Any Major Conference

**Logistics:**
- [ ] Written confirmation from primary AV vendor + backup vendor standing by
- [ ] Separate Wi-Fi networks for staff vs. attendees (classic mistake)
- [ ] Final venue walk-through with stage manager — confirmed in writing
- [ ] Full vendor contact list with mobile numbers — saved offline

**Content & Speakers:**
- [ ] Final presentation files confirmed + USB backup + cloud backup
- [ ] Remote speaker connectivity tested live (Zoom/Teams — real-time check)
- [ ] Updated Run-of-Show in every stage team member's hands

**People:**
- [ ] Attendee registration list + fast check-in solution (QR / kiosks) — tested 72h out
- [ ] Check-in staffing: 1 person per 80 attendees
- [ ] Catering: confirmed final headcount + all dietary requirements verified

**Risk Management:**
- [ ] Clear emergency protocol (security & medical) in place
- [ ] "War Room" — a small dedicated room for production team with independent network
