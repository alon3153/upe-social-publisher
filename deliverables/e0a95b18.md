## B. שדות Salesforce מותאמים — יצירה ידנית (Admin)

אם Salesforce הוא ה-source of truth שלך, הייחוס של ה-referral חייב להתחבר אליו ישירות — הרפרל מזוהה בזמן הכניסה לפייפליין, ומסומן כ-qualified כשה-CRM stage מוכיח שזה הזדמנות אמיתית.

**צור את השדות הבאים ב-Setup → Object Manager → Lead → Fields & Relationships:**

| Field Label | API Name | Type | Length | Notes |
|---|---|---|---|---|
| Referred By | `UPE_ReferredBy__c` | Text | 255 | השדה המרכזי |
| Event Type | `UPE_EventType__c` | Picklist | — | ע"פ options בטופס |
| Participant Range | `UPE_ParticipantRange__c` | Picklist | — | ע"פ options בטופס |
| Entry Point | `UPE_EntryPoint__c` | Text | 100 | service-page / email-sig / etc. |
| Page Source URL | `UPE_PageSource__c` | URL | 255 | עמוד המקור |
| UTM Source | `UPE_UTMSource__c` | Text | 100 | utm_source |
| UTM Medium | `UPE_UTMMedium__c` | Text | 100 | utm_medium |
| UTM Campaign | `UPE_UTMCampaign__c` | Text | 100 | utm_campaign |
| WOM Attributed | `UPE_WOMAttributed__c` | Checkbox | — | Auto-checked בRule |
| Digital Assisted | `UPE_DigitalAssisted__c` | Checkbox | — | לדשבורד KPI |

**ב-Web-to-Lead HTML, ה-`name` attribute של כל שדה מותאם חייב להיות ה-ID הנומרי שמייצר Salesforce** (מתחיל ב-`00N...`) — לא שם ה-API. תוכל למצוא את ה-IDs ב-Setup → Lead Fields → לחיצה על השדה → ה-URL.

## C. JavaScript — Auto-Populate Hidden Fields

הדבק סקריפט זה לפני `</body>` בכל עמוד שבו הטופס מופיע:

```javascript
/**
 * UPE WOM Form — Auto-populate hidden attribution fields
 * Version: 1.0 | DRAFT — Pending Approval
 *
 * Captures: page URL, UTM params, entry point label
 * Writes to: hidden inputs that POST to Salesforce Web-to-Lead
 */

(function () {
  'use strict';

  function getParam(name) {
    var urlParams = new URLSearchParams(window.location.search);
    return urlParams.get(name) || '';
  }

  function getEntryPoint() {
    // Map page path segments to human-readable labels
    var path = window.location.pathname.toLowerCase();
    var map = {
      'incentive':   'service-page-incentive',
      'conference':  'service-page-conference',
      'destinations':'service-page-destinations',
      'about':       'page-about',
      'contact':     'page-contact',
    };
    for (var key in map) {
      if (path.indexOf(key) !== -1) return map[key];
    }
    // Check for email signature referral via query param
    if (getParam('ref') === 'email-sig') return 'email-signature';
    return 'unknown-' + path.replace(/\//g, '-').slice(0, 40);
  }

  function populateField(id, value) {
    var el = document.getElementById(id);
    if (el && value) el.value = value;
  }

  // Wait for DOM
  document.addEventListener('DOMContentLoaded', function () {
    populateField('upe_page_source',  window.location.href);
    populateField('upe_utm_source',   getParam('utm_source'));
    populateField('upe_utm_medium',   getParam('utm_medium'));
    populateField('upe_utm_campaign', getParam('utm_campaign'));
    populateField('upe_entry_point',  getEntryPoint());

    // Store in sessionStorage so re-navigations don't lose UTMs
    if (getParam('utm_source')) {
      sessionStorage.setItem('upe_first_utm_source',   getParam('utm_source'));
      sessionStorage.setItem('upe_first_utm_medium',   getParam('utm_medium'));
      sessionStorage.setItem('upe_first_utm_campaign', getParam('utm_campaign'));
    }

    // Fall back to stored UTMs if not in URL (multi-page journeys)
    if (!getParam('utm_source') && sessionStorage.getItem('upe_first_utm_source')) {
      populateField('upe_utm_source',   sessionStorage.getItem('upe_first_utm_source'));
      populateField('upe_utm_medium',   sessionStorage.getItem('upe_first_utm_medium'));
      populateField('upe_utm_campaign', sessionStorage.getItem('upe_first_utm_campaign'));
    }
  });

})();
```

## G. Salesforce Workflow / Flow — הוראות Admin

יצירת Salesforce Campaign ייעודי לכל טופס מאפשרת ייחוס מדויק של lead source וניטור ביצועי קמפיין — כך ניתן להבין אילו עמודים מייצרים את הלידים האיכותיים ביותר.

### שלב 1: צור Campaign ב-Salesforce
```
Campaign Name:  WOM-Referral-Form
Type:           Referral
Status:         Active
Start Date:     [תאריך הפעלה]
Expected Revenue: TBD
```

### שלב 2: צור Workflow Rule (או Flow) — "Flag WOM Lead"

```
Object:         Lead
Trigger:        Created
Condition:      Lead Source = "Referral - WOM"
                AND UPE_ReferredBy__c ≠ NULL (אם רוצים לוודא שיש מפנה)

Actions:
  1. Field Update → UPE_WOMAttributed__c = TRUE
  2. Field Update → UPE_DigitalAssisted__c = TRUE
  3. Add to Campaign → "WOM-Referral-Form" (Status: Responded)
  4. Task → Create follow-up task for Lead Owner:
             Subject: "🤝 WOM Lead — הפנייה מ: {UPE_ReferredBy__c}"
             Due Date: TODAY + 1
             Priority: High
```

### שלב 3: Report — "Digital-Attributed WOM Leads — Monthly"

```
Report Type:    Leads
Filters:
  - Lead Source = "Referral - WOM"
  - UPE_DigitalAssisted__c = TRUE
  - Created Date = This Month

Columns:
  First Name | Last Name | Company | Title | Email
  UPE_ReferredBy__c | UPE_EntryPoint__c | UPE_EventType__c
  UPE_UTMSource__c | Created Date | Lead Status

Group by: UPE_EntryPoint__c
Summary: Count of Leads

Add to Dashboard: ✅ "WOM Attribution — Monthly KPIs"
```
