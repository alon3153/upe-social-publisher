## ו. הוראות הפקה לצוות

### מה לצלם מכל אירוע עתידי (checklist)
```
☐  B-roll: הגעת קהל + רגע הפתיחה + shot של האולם מלא
☐  B-roll: פרט אחד חריג (מיקרופון, שולחן, food station)  
☐  Talking head: 60 שניות של הפרודיוסר/מנהל פרויקט — "מה למדנו היום"
☐  Screen recording של WhatsApp engagement / poll results
☐  תמונת "before vs. after" של seating/layout
```

### עריכה
- עריכה טובה לShorts = קצב הדוק. גזרו dead air, "אמממ" ורמבול מיותר. השתמשו בטקסט overlay לנקודות מפתח ולפעולות נדרשות.
- פונט: Bold Sans Serif, גדול, ניגוד גבוה (לבן/צהוב על רקע כהה)
- מוזיקה: Instrumental בלבד, volume 15–20% — לא מעל הדיבור
- פורמט: 1080×1920px, אנכי — ממלא את כל המסך לחוויה immersive ומקצועית.

### Title formula לכל Short
```
[מה ש"כולם" עושים / הבעיה] → [מה שאנחנו עושים] — [תוצאה/מספר]
או:
[שאלה שמחדדת כאב] + אמוג'י
```

### Description formula
```
שורה 1: הטיפ בצורת הבטחה (מה הצופה ילמד)
שורה 2: CTA + לינק + #Shorts + 2–3 hashtags ענפיים + #UPE
```
