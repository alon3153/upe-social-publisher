## SERIES BIBLE — מדריך הסדרה

### אסטרטגיה ורציונל

Instagram היא כיום ecosystem שמוביל וידאו, ו-Reels הם המנוע המרכזי של reach, discovery וצמיחת קהל. Reels הם הפורמט המרכזי לגילוי ב-Instagram, ומגיעים ל-2× יותר non-followers מאשר static posts.

הסדרה הזו מיועדת לבנות קהל B2B ממוקד (CMOs, HR Directors, Event Leads) שמכיר את UPE **לפני** שהם צריכים ספק. כל אפיזודה מבוססת על brief אמיתי (מוסתר) — הפורמט הזה ייחודי לענף, בונה אוטוריטה, ומייצר "save-and-share" טבעי.

---

### פרמטרים טכניים לכל אפיזודה

| פרמטר | ספציפיקציה |
|---|---|
| **אורך** | 30–45 שניות (optimal לB2B) |
| **פורמט** | Vertical 9:16, 1080×1920px |
| **Hook** | 0–3 שניות — טקסט על מסך + דיבור בו-זמנית |
| **גופן hook** | Bold, גדול, מרכז מסך, ≤5 מילים |
| **קצב עריכה** | Cut every 2–3 שניות למניעת drop-off |
| **מוסיקה** | Instrumental רקע נמוך — לא distract מהתוכן |
| **Captions** | Auto-captions ON — עברית + אנגלית overlay לפי אפיזודה |
| **Hashtags** | 5–8 ממוקדים (ראה לכל אפיזודה) |
| **פרסום** | יום רביעי, 08:00–09:00 (window B2B engagement) |
| **CTA** | DM-first (לא "link in bio") |

**למה DM-first?** "Send this to..." hooks ו-DM shares הם הsignal האיכותי ביותר שInstagram מודד per-action.

**למה saves?** Saves ו-shares נושאים ~3× משקל אלגוריתמי של לייקים; פוסט שמקבל 50 saves יגיע לreach רחב יותר מפוסט שמקבל 500 לייקים.

### מבנה אחיד לכל אפיזודה (Template)

```
[0:00–0:03]  HOOK — מסך שחור + טקסט bold + שאלה פרובוקטיבית
[0:03–0:10]  THE BRIEF — "הנה מה שהלקוח ביקש" (מוסתר: ללא שם)
[0:10–0:22]  THE CHALLENGE — מה שגרם לנו לעצור ולחשוב
[0:22–0:35]  THE REVEAL — הפתרון שיישמנו + visual proof (footage/photo)
[0:35–0:42]  THE RESULT — מספר אחד חד (ROI / participants / NPS)
[0:42–0:45]  CTA — "יש לכם brief מאתגר? DM אותנו 'BRIEF'"
```

---

### לוגיקת ה-Hook לפי מחקר 2026

הhook — 3 השניות הראשונות — הוא מה שקובע אם מישהו ימשיך לצפות או יגלול הלאה. בנישות business ו-educational, hooks שמובנים על value ו-efficiency מניבים את הביצועים הטובים ביותר.

שלושה סוגי hooks שנסובב בין האפיזודות:
1. **Contrarian Hook** — "כולם היו אומרים לא. אנחנו אמרנו כן."
2. **Mistake Hook** — "הטעות שכמעט הרסה את הכנס הזה"
3. **Specificity Hook** — מספר ספציפי שמייצר סקרנות

## 🎯 Engagement Mechanics — מה יניע את המדדים

### מה מניע saves (×3 אלגוריתמי):
Saves נושאים ~3× משקל אלגוריתמי של לייקים — כשמישהו שומר, Instagram מפרש זאת כ"זה תוכן בעל ערך." הסדרה תייצר saves טבעיים כי event leads שומרים "לפני הbriefing הבא."

### מה מניע comments:
Contradiction hooks מניבים comments ("זה לא יכול להיות נכון"), מה שמשפר את מהירות ה-engagement בגל ה-seed distribution הראשוני.

### מה מניע DMs:
כל CTA מפנה ל-DM עם מילת קוד (BRIEF) — מייצר:
1. Signal איכותי לאלגוריתם
2. Lead ישיר לUPE
3. מדידה של conversion לפי אפיזודה

### מה מניע watch time:
האלגוריתם של Instagram מתמקד ב-watch time ו-session duration — Reels שצופים בהם עד הסוף מקבלים reach אקספוננציאלי. הפורמט hook→challenge→reveal→result שומר על צפייה כי הreveal תמיד מגיע לאחר שהבעיה ברורה.

## ✅ Production Checklist — לפני כל אפיזודה

- [ ] Brief source confirmed (real client case, approved for storytelling)
- [ ] Client / company name fully hidden (brief pixelated, no identifiers)
- [ ] Key result number verified (NPS / headcount / % change)
- [ ] Hook tested: read aloud in 2.5 seconds max
- [ ] On-screen text: ≤5 words per frame
- [ ] Captions auto-generated + manually reviewed
- [ ] Audio: music under -12db (voice priority)
- [ ] Thumbnail: first frame is hook text (not black)
- [ ] Hashtags: 5–8, mix of broad + niche B2B
- [ ] CTA verbal + visual in last 3 seconds
- [ ] Scheduled: Wednesday 08:00–09:00
- [ ] Response team briefed to reply to DMs within 1 hour post-publish
