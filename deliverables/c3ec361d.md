## 📋 תקציר מנהלי (למי שרואה רק עמוד ראשון)

**הבעיה:** מתוך הלידים הנוכחיים ב-Salesforce, 1 ליד מסומן `Other` ו-3 לידים מסומנים `Web` — ייתכן שכולם הגיעו דרך Google Organic (SEO), אך הסיווג הרופף מסתיר זאת. אם לא נתקן את זה, אנחנו לא יודעים באיזה ערוץ לדחוף תקציב וזמן.

**הפתרון:** 3 כלים מיידיים:
1. **מדריך סיווג** לנציג — שאלות 60 שניות לזיהוי המקור האמיתי
2. **ולידציה ב-Salesforce** — שדות חובה + Validation Rule
3. **רטרואקטיב Audit** — סקריפט לסקירת 4 הלידים הקיימים + כל ליד עתידי עם `Other`/`Web`

**מדד הצלחה ברור:** 100% מהלידים החדשים שהזכירו את האתר מסומנים `Google Organic` או `Web` (לא `Other`) — לאחר שבועיים מיישום.

## חלק 1 — מדריך שאלות לנציג מכירות (60 שניות)
### 📄 כרטיס עזר | סיווג Lead Source ב-Salesforce

> **הדפסו + שלחו לנציגים בוואטסאפ/סלאק. RTL.**

---

**כשליד מגיע אליך — שאל (בשיחת חימום או באימייל ראשון):**

> *"אגב, איך הגעת אלינו? חיפשת משהו בגוגל? ראית פוסט? מישהו המליץ?"*

---

**עפ"י התשובה — בחר בשדה `Lead Source` כך:**

| מה אמר/ה הליד | Lead Source שיש לסמן | הסבר קצר |
|---|---|---|
| "חיפשתי בגוגל / ביאהו / בינג" | ✅ **Google Organic** | חיפוש אורגני — SEO |
| "ראיתי פרסומת בגוגל" | Google AdWords | PPC בתשלום |
| "נכנסתי לאתר שלכם / ראיתי את האתר" (ללא פירוט) | ✅ **Web** | כניסה ישירה לאתר — לא ברור המקור |
| "ראיתי בלינקדאין / פייסבוק / אינסטגרם" | Social Media | רשתות חברתיות |
| "חבר/קולגה המליץ" | Word of Mouth / Referral | הפניה |
| "קיבלתי אימייל מכם" | Email | דיוור |
| "ראיתי בכנס / תערוכה" | Trade Show | אירוע |
| "לא יודע / לא זוכר" | **Web** (ברירת מחדל) + הוסף הערה בשדה Notes | **לעולם אל תשאיר `Other`** |

---

> ⚠️ **כלל ברזל:** `Other` = **לעולם לא תקין.** `Other` הורג את הדוחות. אם לא ברור — בחר `Web` וכתוב הערה.

---

**דוגמאות שיחה אמיתיות:**

> *ליד אומר:* "גגלתי 'חברת הפקה לאירועים תל אביב' ומצאתי אתכם"
> *→ סמן:* ✅ **Google Organic**

> *ליד אומר:* "נכנסתי לאתר שלכם ורואה את העבודות שלכם"
> *→ סמן:* ✅ **Web**

> *ליד אומר:* "לא בדיוק זוכר, ראיתי אתכם איפשהו"
> *→ סמן:* **Web** + כתוב בהערות: "מקור לא ברור, כנראה דיגיטלי"

## חלק 2 — הגדרת Salesforce (לאדמין)
### 🔧 Validation Rule — מנע `Other` ריק

העתק-הדבק ישירות ב-Setup → Object Manager → Lead → Validation Rules → New

```
Rule Name: Block_Other_Lead_Source_Without_Note

Error Condition Formula:
AND(
  LeadSource = "Other",
  ISBLANK(Description)
)

Error Message (Hebrew):
"שדה 'Lead Source' מוגדר כ-Other — נא להוסיף הסבר בשדה Notes/Description, או לבחור ערך ספציפי יותר (כגון: Google Organic / Web)."

Error Location: Field → LeadSource
```

---

### 🔧 Validation Rule — חייב Lead Source בכל ליד

```
Rule Name: Require_Lead_Source

Error Condition Formula:
ISBLANK(LeadSource)

Error Message (Hebrew):
"שדה 'Lead Source' הוא חובה — בחר את מקור הליד לפני שמירה."

Error Location: Field → LeadSource
```

---

### 🔧 Restrict Picklist (הוראה לאדמין)

נעל את שדה `Lead Source` כ-Restricted Picklist כך שנציגים לא יוכלו להקליד ערכים חופשיים.

**Setup → Object Manager → Lead → Fields & Relationships → Lead Source → Edit → סמן "Restrict picklist to the values defined in the value set"**

הערכים המאושרים לרשימה (Picklist Values) — רק אלה:

```
Google Organic
Google AdWords
Social Media – LinkedIn
Social Media – Facebook/Instagram
Web (Direct)
Email Campaign
Referral / Word of Mouth
Trade Show / Event
Partner
Cold Outreach (Rep)
```

> ❌ הסר: `Other` — **או** השאר אך עם Validation Rule שמאלץ הסבר.

## חלק 4 — דוח Salesforce להפעלה שוטפת (הוראה לאדמין)

### דוח: "לידים עם Lead Source חשוד — בדיקה שבועית"

צור דוח על Lead ו-Contact records שנוצרו ב-90 הימים האחרונים בהם `Lead Source = 'Web'` או `Lead Source = 'Other'` — ואלו מועמדים לבדיקה שמא הם Google Organic שלא סווגו.

**הגדרות הדוח:**

```
Object: Leads
Filters:
  - Lead Source = "Other" OR Lead Source = "Web"
  - Created Date = Last 90 Days (או Rolling: This Month)
Columns:
  - Lead Name
  - Company
  - Lead Source
  - Created Date
  - Lead Owner
  - Description / Notes
  - Last Activity Date

Schedule: שלח לאלון + ראש צוות מכירות — כל יום ראשון, 09:00
```
