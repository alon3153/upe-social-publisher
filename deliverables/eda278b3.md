## 🔑 שלב 1 — יצירת/חידוש מפתח Gemini API (Auth Key)

> ⚠️ **שים לב שינוי קריטי (מאי–ספטמבר 2026):** מאז 28 במאי 2026, מפתחות שנוצרים ב-AI Studio הם "Auth keys" — כלומר קשורים לחשבון שירות ומוגבלים ל-Gemini API כברירת מחדל. אם עמודת "Key Type" מציגה **Standard** — יש מפתח ישן, וגוגל ממליצה ליצור חדש ולהעביר אליו את השימוש. כל המשתמשים חייבים לעבור ל-Auth keys לפני ספטמבר 2026 כדי לשמור על גישה.

### הוראות שלב-אחר-שלב:

```
שלב 1: כניסה ל-Google AI Studio
  URL: https://aistudio.google.com/apikey
  → היכנס עם חשבון Google של UPE (חשבון ארגוני מועדף)

שלב 2: יצירת מפתח חדש
  → לחץ "Create API key"
  → בחר: "Create API key in new project" (לפשטות מקסימלית)
     או בחר פרויקט Google Cloud קיים של UPE

שלב 3: העתקת המפתח ואחסון מאובטח
  → העתק את המפתח מיד עם יצירתו
  → שמור ב-Password Manager של הצוות / Secrets Manager
  → אל תשמור בקוד גלוי / Google Sheets

שלב 4: אימות סוג המפתח
  → ודא שעמודת "Key Type" מציגה "Auth" (לא "Standard")
  → אם מציגה "Standard" — צור מפתח חדש לפי השלבים מעל

שלב 5: הגדרת משתנה סביבה
  שם המשתנה:  GEMINI_API_KEY
  ערך:        [המפתח שהעתקת]
```

חשוב: הגבל את המפתח ל-Generative Language API ב-AI Studio — החל מ-19 ביוני 2026 מפתחות לא מוגבלים נחסמים.

ספריות הלקוח של Google מחפשות אוטומטית את המשתנה `GEMINI_API_KEY` או `GOOGLE_API_KEY`, ואם שניהם מוגדרים — `GOOGLE_API_KEY` גובר.

## ✅ שלב 2 — בדיקת תקינות המפתח (Validation)

לאחר יצירת המפתח, הפעל בדיקה מהירה:

```bash
# בדיקת curl — מאשרת שהמפתח פעיל (Windows / macOS / Linux)
curl -s -H "x-goog-api-key: YOUR_API_KEY_HERE" \
  "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"Hello, respond with OK only."}]}]}' \
  | grep -o '"text".*'

# תשובה צפויה אם המפתח תקין:
# "text": "OK"

# תשובה אם המפתח שגוי / חסום:
# "code": 403 / "message": "API key not valid"
```

## 📊 שלב 3 — הגדרת מדידת AEO על מנוע שני (Gemini)

לאחר שהמפתח פעיל, הפעל מדידה מובנית. קריטריון ההצלחה: **השוואת תקופות תואמות על 2 מנועים.**

### מחסנית מדידה מינימלית (ניתנת להפעלה מיידית):

| שכבת מדידה | מנוע 1 (קיים) | מנוע 2 — Gemini (חדש) | כלי |
|---|---|---|---|
| AI Impressions / Citations | Google Search Console → Performance → "Web" (AI Overviews) | Gemini API + Prompt tracking | Search Console / ידני |
| AI Referral Sessions | GA4 → "AI Assistant" channel | referral: gemini.google.com | GA4 |
| Citation Rate (ידני) | מנוע קיים | Gemini / AI Mode | Google Sheet tracking |
| Share of Answer | מנוע קיים | Gemini | Profound / Otterly / AthenaHQ |

> 📌 Google Search Console כולל קליקים ו-Impressions מ-AI Overviews ו-AI Mode בדוח ה-Performance תחת "Web". מאוגוסט 2026 גם דוחות ה-AI הגנרטיבי ב-Search Console מציגים אילו עמודים הופיעו ב-AI features (Impressions בלבד, ללא קליקים).
