# טיוטה — הצהרת נגישות (לשני האתרים; להתאים את הסוגריים המרובעים)

> נדרש לפי תקנות שוויון זכויות לאנשים עם מוגבלות (התאמות נגישות לשירות), התשע"ג-2013, תקנה 35. להציב בעמוד `/accessibility` ולקשר מהפוטר של כל עמוד. **סטטוס:** טיוטה — למלא רכז/ת נגישות ולעדכן את רשימת הפערים אחרי התיקונים.

**עדכון אחרון:** [תאריך]

## המחויבות שלנו
[א. אפרודקשיין ייעוץ בע"מ (Uproduction Events)] פועלת כדי שאתר [seaesta2026.com / upe.co.il] יהיה נגיש לאנשים עם מוגבלות, מתוך אמונה שלכל אדם זכות שווה למידע ולשירות. האתר נבנה בהתאם להנחיות WCAG 2.0 ברמה AA (ת"י 5568), ככל האפשר.

## מה בוצע באתר
- מבנה סמנטי: כותרות, אזורי ניווט וקישור "דלג לתוכן" בראש כל עמוד.
- ניווט מלא במקלדת (Tab / Enter / Esc) עם סימון פוקוס בולט.
- טקסט חלופי לתמונות, ותיאור לסרטונים.
- ניגודיות צבעים בהתאם ל-AA [לאחר תיקון ה-tokens].
- גופנים מוגדלים כברירת מחדל ותמיכה בהגדלה עד 200% ללא אובדן תוכן.
- כיבוד הגדרת "הפחתת תנועה" של מערכת ההפעלה — אנימציות ופרלקסה מבוטלות אוטומטית.
- טפסים עם תוויות, הודעות שגיאה מוקראות (`aria-live`) והנחיות מילוי.
- שפת העמוד וכיוון הטקסט (עברית, RTL) מוגדרים לקוראי מסך.
- תאימות: Chrome, Safari, Firefox, Edge בגרסאות עדכניות; NVDA ו-VoiceOver.
